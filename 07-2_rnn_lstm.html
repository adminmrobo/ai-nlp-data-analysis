큰 그림 — 이 회차가 흘러가는 4단계 (펼쳐 보기)

① 신경망 기초

뉴런은 "가중합 → 활성화 함수" 두 동작뿐이다. 이 단순한 계산을 층층이 쌓으면 복잡한 패턴을 배운다. 활성화 함수가 없으면 아무리 쌓아도 일차함수 하나와 같다.

② RNN과 기울기 소실

RNN은 매 단계 기억에 같은 계수를 곱하며 넘긴다. 계수가 1보다 작으면 기억이 거듭제곱으로 사라지고(소실), 1보다 크면 폭발한다(폭주). 그래서 10~20단계 넘는 관계를 배우기 어렵다.

③ RNN과 LSTM

RNN은 걸음마다 정보를 조금씩 잃어 긴 문장의 앞부분을 잊는다(기울기 소실). LSTM은 셀 상태와 세 게이트로 필요한 정보를 오래 지킨다.

1신경망 기초

뉴런 하나의 일 — 곱하고, 더하고, 활성화 함수로 거르기

구조: 입력 · 가중치 · 편향 · 활성화 함수함수: 시그모이드 · tanh · ReLU

전통적인 분류·회귀 모델과 규칙 기반 모델은 수많은 픽셀이나 긴 텍스트처럼 복잡한 데이터에서 한계를 보여요. 신경망은 아주 단순한 계산 단위(뉴런)를 많이 이어 붙여 이를 풀어요. 뉴런 하나는 입력에 가중치를 곱해 더하고, 활성화 함수로 비선형성을 더해 내보내요.

이 칸에서 가져갈 한 가지

뉴런은 "가중합 → 활성화 함수" 두 동작뿐이다. 이 단순한 계산을 층층이 쌓으면 복잡한 패턴을 배운다. 활성화 함수가 없으면 아무리 쌓아도 일차함수 하나와 같다.

왜 이 방법을 쓰나

문제 상황

"배송 빠르고 좋아요"와 "배송 빠르지만 별로예요"처럼 단어 조합이 복잡하게 얽힌 글을 판정해야 해요.

앞 방법의 한계

규칙 기반은 규칙이 폭발하고, 로지스틱 회귀 같은 선형 모델은 단어 점수를 곧게 더할 뿐이라 복잡한 조합을 잡기 어려워요.

해법

뉴런 여러 개가 각자 다른 조합을 잡게 하고, 그 결과를 다음 층 뉴런이 다시 조합하게 쌓아요. 활성화 함수가 곧은 선을 휘게 만들어요.

쉽게 말하면 한 명이 모든 걸 판단하는 대신, 여러 명이 각자 한 가지씩 보고 그 의견을 팀장이 다시 모으는 거예요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

가중합 z는 어떻게 계산해요?

학교 수학으로 보면 일차식(중학교) — y = ax + b의 여러 변수 버전

z = w₁x₁ + w₂x₂ + b, 출력 = 활성화 함수(z)
x₁, x₂입력(긍정·부정 단어 수)
w₁, w₂가중치(각 입력의 중요도·방향)
b편향(기본 성향)
활성화 함수시그모이드·tanh·ReLU
숫자로 한 번 해 보기긍정 2, 부정 1, 편향 0 → z = 0.8 × 2 − 1.2 × 1 + 0 = 0.4시그모이드(0.4) ≈ 0.599, tanh(0.4) ≈ 0.380, ReLU(0.4) = 0.4부정 2개로 바꾸면 z = −0.8 → ReLU = 0

결국 일차식에 S자나 꺾인 선을 씌우는 거네요. 이걸 수천 개 쌓는 거고요.

일상으로 치면

심사위원 여러 명이 각자 한 기준으로 점수를 매기고, 일정 점수를 넘을 때만 "추천"을 표시해요. 위원장이 그 표시들을 다시 모아 결정하죠.

자연어 처리로는

교안: 신경망의 각 뉴런은 간단한 계산 유닛으로, 여러 입력을 받아 처리한 뒤 출력을 내보내고, 이 과정에서 활성화 함수로 비선형적인 특성을 부여해요. 시그모이드는 0~1, tanh는 −1~1, ReLU는 0보다 작으면 0·크면 그대로 내보내요.

조수(하루)

가중치(긍정 +0.8, 부정 −1.2)는 설명용 예시값이에요.

실험 — 뉴런 하나 계산기 — 가중합과 활성화 함수

자세한 풀이 — 신경망을 활용한 인공지능 모델(교안) (펼쳐 보기)
  1. 전통 모델의 한계: 분류·회귀 모델은 의사결정이나 기계 제어에 쓰지만, 수많은 픽셀의 이미지나 텍스트처럼 복잡한 데이터의 분류는 어려워요.
  2. 뉴런: 여러 입력 × 가중치를 더하고 편향을 더한 뒤 활성화 함수를 통과시켜 출력해요.
  3. 활성화 함수: 비선형성을 줘서 층을 쌓을 의미가 생겨요(시그모이드 0~1, tanh −1~1, ReLU max(0, z)).
  4. 층 쌓기: 앞 층의 출력이 다음 층의 입력이 되어 점점 복잡한 패턴을 잡아요.

이 칸의 한계 · 보통 신경망은 입력을 한꺼번에 받아요. 문장처럼 순서가 있는 데이터에서 "앞 단어"를 기억하며 읽으려면 순환 구조가 필요해요. 다음 칸의 RNN이에요.

업무에 쓸 때 알아 둘 것 (펼쳐 보기)

데이터 분석으로 치면

신경망 결과를 설명할 때 "가중합 + 활성화 함수"라는 뉴런의 일을 먼저 말해 주면 비전공 의사결정자의 이해가 빨라요.

층이 깊어질수록 왜 그런 판단을 했는지 설명하기는 어려워져요.

2RNN과 기울기 소실

RNN — 앞 단어를 기억하며 읽기, 그리고 희석되는 기억

구조: 은닉 상태 hₜ = tanh(W·hₜ₋₁ + U·xₜ + b)한계: 기울기 소실·폭주 · 장기 의존성

순환 신경망(RNN)은 이전 시점의 정보(은닉 상태)를 현재 단어와 합쳐 다음 시점으로 넘기며 문장을 읽어요. 같은 가중치를 매 시점 다시 써서 길이가 다른 문장도 처리해요. 교안은 이를 물이 탱크에서 탱크로 흐르는 수로에 빗대요. 그런데 먼 거리를 흐르는 동안 처음 물(정보)은 점점 희석돼요.

이 칸에서 가져갈 한 가지

RNN은 매 단계 기억에 같은 계수를 곱하며 넘긴다. 계수가 1보다 작으면 기억이 거듭제곱으로 사라지고(소실), 1보다 크면 폭발한다(폭주). 그래서 10~20단계 넘는 관계를 배우기 어렵다.

왜 이 방법을 쓰나

문제 상황

"나는 한국에서 태어났고, 프랑스에서 자랐으며, 현재는 … 원어민처럼 ___어를 구사한다." 빈칸을 채우려면 맨 앞 "한국"을 기억해야 해요(교안).

앞 방법의 한계

RNN은 단계마다 기억에 비슷한 계수(tanh와 가중치)를 곱해요. 0.8을 20번 곱하면 약 1%만 남아요. 처음 정보가 뒤쪽에 거의 영향을 못 줘요.

해법

곱셈 대신 덧셈 경로로 기억을 넘기고, 무엇을 잊고 담을지 게이트로 고르는 LSTM이 이 문제를 풀어요(다음 칸).

쉽게 말하면 귓속말 전달 놀이에서 사람이 늘어날수록 처음 말이 흐려지는 것과 같아요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

0.8을 계속 곱하면 왜 그렇게 빨리 줄어요?

학교 수학으로 보면 거듭제곱, 등비수열(고등학교)

n단계 뒤 남은 비율 = wⁿ (w: 단계마다 남는 비율)
w한 단계를 지날 때 남는 비율
n지나온 단계 수
wⁿw를 n번 곱한 값(등비수열의 n번째 항)
숫자로 한 번 해 보기0.8² = 0.640.8⁵ ≈ 0.3280.8¹⁰ ≈ 0.107, 0.8²⁰ ≈ 0.012(약 1%)

매번 20%씩만 잃어도 스무 번이면 거의 다 사라지는군요. 반대로 1.2면 폭발하고요.

일상으로 치면

열 명이 귓속말을 전하면 처음 문장이 뭉개져요. 한 명이 80%씩만 정확히 전해도 열 명 뒤엔 약 11%만 남아요.

자연어 처리로는

교안의 RNN 특징: 같은 가중치를 시간 단계마다 공유, 가변 길이 시퀀스 처리, 시간적 의존성 모델링, 자연어·음성·시계열에 적합. 한계:
① 긴 시퀀스에서 역전파 중 기울기가 소실되거나 폭발
② 장기 의존성 학습이 어려움
③ 기울기 클리핑으로도 근본 해결이 어렵고
④ 실전에서 10~20단계 이상의 의존성은 학습이 어려움.

박사

단계마다 남는 비율과 단어 거리를 바꿔 보세요. 첫 단어의 정보가 얼마나 남나요?

주판봇

0.9면 거의 다 남는 거잖아! 문제없어.

초파리 연구원

0.9를 30번 곱해 봐. 4%야. 문장이 길면 앞이 사라져.

조수(하루)

"남는 비율"은 단계마다 같은 계수를 곱하는 단순화예요. 실제 기울기는 단계마다 조금씩 달라요.

실험 — 기억이 희석되는 속도 — 거듭제곱

자세한 풀이 — RNN의 구조와 한계(교안) (펼쳐 보기)
  1. 은닉 상태: hₜ = tanh(W·hₜ₋₁ + U·xₜ + b). 현재 입력 xₜ와 이전 은닉 상태 hₜ₋₁을 합쳐 새 기억을 만들어요.
  2. 시퀀스가 중요한 이유: 문장의 뜻은 단어 순서에 따라 달라지고, 앞 단어가 다음 단어 예측에 영향을 줘요.
  3. 수로 비유: 물(정보)이 탱크에서 탱크로 흐르고, tanh가 물의 양을 −1~1로 조절하는 필터 역할을 해요. 긴 거리를 흐르면 처음 물이 희석돼요.
  4. 한계: 기울기 소실·폭주, 장기 의존성, 같은 가중치 반복 사용으로 문제 증폭, 기울기 클리핑으로도 근본 해결이 어려움.
  5. 개선: LSTM — 셀 상태로 장기 정보 보존, 망각·입력·출력 게이트로 정보 선택 관리.

이 칸의 한계 · 기억을 곱셈으로만 넘기는 한 소실은 피할 수 없어요. 덧셈 경로와 게이트를 가진 LSTM을 다음 칸에서 RNN과 겨뤄 봐요.

업무에 쓸 때 알아 둘 것 (펼쳐 보기)

데이터 분석으로 치면

긴 리뷰·상담 기록을 순환 신경망으로 분석한다면, 길이별로 성능을 따로 재서 긴 글에서 떨어지는지 확인해요.

긴 글이 많으면 LSTM이나 트랜스포머 계열을 검토해요.

3RNN과 LSTM

앞 단어를 기억하며 읽기 — RNN과 LSTM

방법: 순환 신경망(RNN) · LSTM일상: 긴 문장의 앞부분 기억하기

RNN은 이전 시점의 정보(은닉 상태)를 현재 단어와 합쳐 다음 시점으로 넘기며 읽어요. 교안은 이를 물이 탱크에서 탱크로 흐르는 수로에 빗대요. tanh라는 수문이 물의 양을 −1~1로 조절하는데, 먼 길을 흐르는 동안 처음 물은 점점 희석돼요.

이 칸에서 가져갈 한 가지

RNN은 걸음마다 정보를 조금씩 잃어 긴 문장의 앞부분을 잊는다(기울기 소실). LSTM은 셀 상태와 세 게이트로 필요한 정보를 오래 지킨다.

왜 이 방법을 쓰나

문제 상황

"나는 한국에서 태어났고, 프랑스에서 자랐으며, … 원어민처럼 ○○○를 구사한다"에서 빈칸을 맞히려면 문장 맨 앞의 "한국"을 기억해야 해요(교안).

앞 방법의 한계

RNN은 같은 가중치를 반복해 곱하며 걸어가서, 먼 앞부분의 정보와 학습 신호(기울기)가 사라지거나 폭주해요. 실전에서는 10~20단계 이상의 의존을 배우기 어려워요(교안).

해법

① LSTM은 정보를 실어 나르는 고속도로(셀 상태)를 따로 두고
② 망각 게이트(버릴 것)
③ 입력 게이트(새로 담을 것)
④ 출력 게이트(내보낼 것)로 흐름을 조절해요.

쉽게 말하면 수로(RNN)는 멀리 갈수록 물이 새지만, 밸브 달린 메인 파이프(LSTM)는 필요한 물을 끝까지 보내요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

"점점 희석된다"는 게 숫자로 얼마나 빨리 사라진다는 거예요?

학교 수학으로 보면 고등학교 수학의 지수함수(0.8을 거듭 곱하기)예요.

RNN: h_t = tanh(W_h·h_(t−1) + W_x·x_t + b) → 첫 정보 ≈ w^t · LSTM: C_t = f_t × C_(t−1) + i_t × C̃_t → 첫 정보 ≈ f^t
h_t지금 시점의 은닉 상태(기억)
w걸음마다 남기는 비율(단순화한 값)
f_t망각 게이트. 시그모이드로 0(지움)~1(유지)
숫자로 한 번 해 보기RNN w = 0.8: 10단어 뒤 0.8¹⁰ ≈ 0.107(10.7%), 20단어 뒤 0.8²⁰ ≈ 0.012(1.2%)5% 아래로 잊기까지: log 0.05 ÷ log 0.8 ≈ 13.4 → 14단어LSTM f = 0.97: 20단어 뒤 0.97²⁰ ≈ 0.54(54%)

0.8과 0.97은 별 차이 없어 보이는데 스무 번 곱하니 1.2%와 54%! 거듭제곱의 힘이네요.

일상으로 치면

긴 수로로 물을 보내면 중간중간 새고 증발해서 끝에는 처음 물이 거의 안 남아요. 밸브 달린 메인 파이프는 필요한 물만 골라 끝까지 보내죠.

자연어 처리로는

RNN은 시간 단계마다 같은 가중치를 공유해 길이가 다른 문장을 처리하지만, 기울기 소실·폭주로 장기 의존 학습이 어려워요. LSTM은 셀 상태의 덧셈 경로로 기울기를 보존하고 게이트로 정보를 골라 담아요(교안의 "물탱크·밸브" 비유). 다만 이 페이지의 w^t 그림은 원리를 보이려고 단순화한 모형이에요.

조수(하루)

기억이 남는 양은 w^t, f^t로 단순화한 설명용 모형이에요. 실제 게이트 값은 단어마다 달라져요.

실험 — 첫 단어 정보가 남는 양 — RNN 대 LSTM

자세한 풀이 — LSTM의 게이트와 활용(교안) (펼쳐 보기)
  1. 망각 게이트: 이전 기억 가운데 얼마를 남길지 0(다 버림)~1(다 남김)로 정해요. 식으로는 f_t = σ(W_f·[h_(t−1), x_t] + b_f)이고, σ(시그모이드)가 0~1을 만드는 장치예요.
  2. 입력 게이트: 새로 들어온 정보를 얼마나 담을지 정해요. 담을 후보는 tanh로 −1~1 사이로 다듬어요. 식으로는 i_t(담을 비율)와 C̃_t(후보)예요.
  3. 셀 상태(기억 통로): 남길 만큼 남기고 새 정보를 더해요. 곱셈만 거듭하지 않고 덧셈으로 이어져 기억이 쉽게 사라지지 않아요. 식으로는 C_t = f_t × C_(t−1) + i_t × C̃_t예요.
  4. 출력 게이트: 기억 가운데 이번에 내보낼 부분을 걸러요. 식으로는 h_t = o_t × tanh(C_t)예요.
  5. 활용: ① 감성 분석 ② 개체명 인식(Bi-LSTM + CRF) ③ 언어 모델링(다음 단어 예측·문장 완성·문법 교정) ④ 금융 뉴스·의료 기록·계약서 분석.

이 칸의 한계 · RNN·LSTM은 문장을 읽고 분류하거나 다음 단어를 예측하지만, "문장을 받아 다른 문장(번역·요약)을 만드는" 일에는 읽는 쪽과 쓰는 쪽을 나눈 구조가 필요해요.

업무에 쓸 때 알아 둘 것 (펼쳐 보기)

고객 리뷰 감성 분석, 고객 문의 자동 분류, 금융 뉴스 감성 기반 지표, 문법 오류 검출에 LSTM이 쓰였어요(교안 산업별 사례).

요즘은 같은 일을 트랜스포머 기반 모델(8~9회차)이 더 잘하는 경우가 많아요. LSTM은 적은 자원·짧은 순서 데이터에서 여전히 쓰여요.

교안의 파이썬 코드로 보면 (몰라도 됩니다)
self.embedding = nn.Embedding(vocab_size, embedding_dim)단어 번호를 단어 벡터로 바꾸는 층이에요(4·6회차).
self.lstm = nn.LSTM(embedding_dim, hidden_dim, batch_first=True)단어 벡터를 순서대로 읽는 LSTM 층이에요.
prediction = self.sigmoid(self.fc(hidden))마지막 기억(은닉 상태)으로 긍정 확률(0~1)을 내요.

정리

칸새로 생긴 능력남은 한계
① 신경망 기초뉴런은 "가중합 → 활성화 함수" 두 동작뿐이다. 이 단순한 계산을 층층이 쌓으면 복잡한 패턴을 배운다. 활성화 함수가 없으면 아무리 쌓아도 일차함수 하나와 같다.뉴런을 쌓아도 입력 순서(앞 단어)를 기억하지 못함
② RNN과 기울기 소실RNN은 매 단계 기억에 같은 계수를 곱하며 넘긴다. 계수가 1보다 작으면 기억이 거듭제곱으로 사라지고(소실), 1보다 크면 폭발한다(폭주). 그래서 10~20단계 넘는 관계를 배우기 어렵다.먼 거리의 관련 정보를 연결하기 어려움(장기 의존성)
③ RNN과 LSTMRNN은 걸음마다 정보를 조금씩 잃어 긴 문장의 앞부분을 잊는다(기울기 소실). LSTM은 셀 상태와 세 게이트로 필요한 정보를 오래 지킨다.문장을 한 단어씩 읽어 길이만큼 걸음이 필요하고, 문장을 만들어 내지는 못함
