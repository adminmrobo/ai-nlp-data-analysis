기계가 말을 "알아들으려면" 무엇을 할 줄 알아야 하고, 그 능력은 누가 만들까?

딥러닝과 자연어

영화평이 수만 개, 댓글이 100만 건이에요. 사람이 하나하나 읽고 "좋다는 건지 나쁘다는 건지" 정할 수 없습니다.

큰 그림 — 이 회차가 흘러가는 4단계 (펼쳐 보기)

판단과 인식 → 규칙과 학습 → 딥러닝과 자연어 → 다음 쪽.

① 판단과 인식

판단은 정보로 결론을 내리는 일, 인식은 보는 순간 대상을 알아보는 일이다. 자율주행 버스처럼 둘을 함께 쓰면 복잡한 일을 해낸다.

② 규칙과 학습

규칙 기반은 사람이 조건을 쓰고, 머신러닝은 과거 데이터에서 조건을 찾는다. 그래서 머신러닝에는 데이터가 필요하다.

③ 딥러닝과 자연어

말의 뜻은 단어 하나가 아니라 뉘앙스와 맥락이 정한다. 그래서 자연어 분석은 "좋다·나쁘다"만이 아니라 "얼마나"와 "무슨 기준으로"를 본다.

④ 다음 쪽

말과 글은 엑셀 표(정형 데이터)와 무엇이 달라서 분석이 어려울까?

1판단과 인식

AI의 두 능력 — 판단과 인식

방법: 판단 · 인식일상: 우산 챙기기, 자율주행 버스

교안은 인공지능을 "사람의 사고와 행동을 흉내 내는 기술"이라고 정의하고, 크게 두 능력으로 나눠요. 정보를 보고 결론을 내리는 판단, 보는 순간 대상을 알아보는 인식이에요.

이 칸에서 가져갈 한 가지

판단은 정보로 결론을 내리는 일, 인식은 보는 순간 대상을 알아보는 일이다. 자율주행 버스처럼 둘을 함께 쓰면 복잡한 일을 해낸다.

왜 이 방법을 쓰나

문제 상황

"인공지능"이라는 말은 너무 넓어요. 회사에서 AI를 쓴다고 할 때 무엇을 맡기는지부터 나눠야 합니다.

앞 방법의 한계

그냥 "똑똑한 프로그램"이라고 보면, 대출 심사와 얼굴 인식처럼 성격이 다른 일을 한 가지로 착각하기 쉬워요.

해법

교안처럼 "결론을 내리는 일(판단)"과 "무엇인지 알아보는 일(인식)"로 나누면, 어떤 데이터와 방법이 필요한지 보여요.

쉽게 말하면 판단은 "우산을 챙길까?"에 답하는 것, 인식은 창밖을 보고 "비가 오네"라고 알아보는 거예요.

일상으로 치면

아침에 일기예보를 보고 우산을 챙길지 정하는 건 판단이에요. 창밖을 보는 순간 "비 온다"라고 아는 건 인식이고요.

자연어 처리로는

대출 심사·질병 진단·법률 조언은 판단, 사진 속 사물 찾기·음성 인식·패턴 인식은 인식이에요. 자연어 처리에서는 "이 문장이 무슨 뜻인지 알아보기(인식)"와 "그래서 긍정인지 부정인지 정하기(판단)"가 이어져요.

조수(하루)

교안 예시로 만든 카드예요. 기록은 남기지 않아요.

실험 — 이것은 판단일까, 인식일까?

자세한 풀이 — 판단과 인식(교안 정리) (펼쳐 보기)
  1. 판단(Judgment): 주어진 정보를 바탕으로 규칙이나 경우에 따라 결론을 내리는 과정. 예: 대출 심사, 질병 진단, 법률 조언.
  2. 인식(Recognition): 대상을 식별하거나 구분하는 능력. 예: 이미지 인식, 음성 인식, 패턴 인식.
  3. 둘의 조합: 자율주행 버스는 차량·보행자를 인식하고(장애물 감지), 피하거나 멈추기로 판단해요.
  4. 만드는 원리: 데이터를 바탕으로 사고·판단하는 프로그램(알고리즘)을 만들고, 빅데이터와 컴퓨팅 기술 발달로 빠르게 성장했어요.

이 칸의 한계 · 판단과 인식이 "무엇"인지는 알았지만 "어떻게" 만드는지는 아직이에요. 사람이 규칙을 써 줄까, 데이터에서 배우게 할까? 다음 칸의 질문이에요.

업무에 쓸 때 알아 둘 것 (펼쳐 보기)

데이터 분석으로 치면

AI 도입 회의에서 맡길 일을 "판단"과 "인식"으로 나눠 적으면, 필요한 데이터(결과 기록 대 사진·음성)와 실패했을 때의 책임이 분명해져요.

실제 서비스는 둘이 섞여 있어요. 인식이 틀리면 판단도 틀린다는 점을 함께 점검해요.

2규칙과 학습

대출 심사 기준은 누가 정하나 — 규칙 기반과 머신러닝

방법: 규칙 기반 · 머신러닝일상: 신용대출 심사

교안은 신용대출 순서도를 예로 들어요. 소득, 카드 지출, 직업 같은 조건을 예·아니오로 따라가는 방식이 규칙 기반이에요. 같은 조건을 과거 데이터에서 알고리즘이 스스로 찾으면 머신러닝입니다.

이 칸에서 가져갈 한 가지

규칙 기반은 사람이 조건을 쓰고, 머신러닝은 과거 데이터에서 조건을 찾는다. 그래서 머신러닝에는 데이터가 필요하다.

왜 이 방법을 쓰나

문제 상황

대출 신청이 하루 수천 건 들어와요. 누구에게 빌려줄지 일관된 기준이 필요합니다.

앞 방법의 한계

예전에는 은행 전문가가 경험으로 "소득은 이만큼, 카드 지출은 이만큼"을 정했어요. 조건이 많아지면 사람이 모든 조합을 써 내기 어렵습니다.

해법

제때 갚은 사람과 못 갚은 사람의 지난 기록을 주고, 두 무리를 가장 잘 나누는 기준을 알고리즘이 찾게 해요.

쉽게 말하면 선배의 감을 받아 적는 대신, 지난 심사 기록 수백 건을 펼쳐 놓고 갈림길을 찾는 거예요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

데이터로 "기준을 찾는다"는 게 정확히 뭘 계산하는 거예요?

학교 수학으로 보면 중학교 수학의 부등식과 비율이에요.

승인 ⇔ 월소득 ≥ T₁ 그리고 카드지출 비율 ≤ T₂ · 정확도 = 맞게 판정한 사람 수 ÷ 전체
T₁, T₂승인 기준이 되는 두 문턱값
≥, ≤이상, 이하. 부등식으로 쓴 규칙
정확도판정과 실제 결과(갚음·연체)가 같은 비율
숫자로 한 번 해 보기전문가 규칙: T₁ = 300만 원, T₂ = 60%데이터 기준: T₁은 25만 원, T₂는 4%p 간격으로 바꿔 가며 지난 200건에서 정확도가 가장 높은 조합을 고름 → T₁ = 325만 원, T₂ = 70%새 신청자 1,000명 정확도: 전문가 규칙 80.3%, 데이터 기준 82.4%

조건의 모양(부등식)은 같고, 문턱값을 사람이 정하느냐 데이터가 정하느냐의 차이였네요!

일상으로 치면

신입 심사역은 선배의 감(규칙)을 배우기도 하고, 지난 몇 년의 심사 기록을 보며 스스로 감을 잡기도 해요.

자연어 처리로는

규칙 기반은 개발자가 전문가에게 들은 조건을 코딩해요(규칙 설계 → 코딩 → 테스트). 머신러닝은 데이터 수집 → 모델 학습 → 검증 → 최적화로 기준을 만들고, 처음 보는 신청자에게도 학습한 패턴으로 판정합니다. 대신 데이터가 적거나 치우치면 기준도 틀어져요.

실험 — 전문가 규칙 대 데이터로 찾은 기준

자세한 풀이 — 규칙 기반과 머신러닝(교안 비교표) (펼쳐 보기)
  1. 문제 해결 방식: 규칙 기반은 명시적 규칙, 머신러닝은 데이터 기반 패턴 학습이에요.
  2. 프로그램 작성: 규칙 기반은 개발자가 모든 규칙을 정의하고, 머신러닝은 알고리즘이 데이터로부터 학습해요.
  3. 잘 푸는 문제: 규칙 기반은 규칙이 분명한 문제, 머신러닝은 복잡하고 변하는 패턴의 문제예요.
  4. 적응과 예측: 규칙 기반은 프로그래밍된 규칙 안에서만, 머신러닝은 학습한 패턴으로 새 상황도 예측해요.
  5. 필요한 것: 규칙 기반에는 전문가가, 머신러닝에는 데이터가 필요해요. 데이터의 중요성이 커진 이유입니다.

이 칸의 한계 · 교안의 "치와와 대 머핀" 사진처럼 점 세 개·흰 부분·갈색 같은 특징을 사람이 정해서 나누는 방식은 쉽게 헷갈려요. 두 살 아이는 규칙 없이 익숙한 패턴으로 알아보죠. 이 "인식"을 흉내 낸 것이 신경망·딥러닝(7회차)입니다.

3딥러닝과 자연어

규칙으로 안 되는 것 — 딥러닝과 자연어 분석

방법: 신경망·딥러닝 · 감성 분석일상: 치와와 대 머핀

교안의 치와와 대 머핀 사진은 "점 세 개, 흰 부분, 갈색"이라는 사람의 기준으로는 나눌 수 없어요. 두 살 아이는 규칙 없이 익숙한 패턴으로 알아보죠. 이 경험 기반 인식을 흉내 낸 것이 신경망·딥러닝이고, 말과 글에서는 감성 분석과 텍스트 요약으로 이어집니다.

이 칸에서 가져갈 한 가지

말의 뜻은 단어 하나가 아니라 뉘앙스와 맥락이 정한다. 그래서 자연어 분석은 "좋다·나쁘다"만이 아니라 "얼마나"와 "무슨 기준으로"를 본다.

왜 이 방법을 쓰나

문제 상황

영화평이 수만 개, 댓글이 100만 건이에요. 사람이 하나하나 읽고 "좋다는 건지 나쁘다는 건지" 정할 수 없습니다.

앞 방법의 한계

"좋다·추천"은 긍정, "실망"은 부정처럼 단어 목록으로 정하면 "참 잘~하네요"(비꼼)나 "아주 잘한다"(정도)를 놓쳐요.

해법

신경망은 문장 전체의 패턴을 배워 방향(긍정·부정·중립)과 정도를 함께 추정해요. 요즘은 이 판단을 AI에게 직접 시키기도 합니다.

쉽게 말하면 단어 하나로 기분을 맞히는 대신, 말투와 앞뒤 사정을 같이 보는 거예요.

일상으로 치면

친구가 "잘~한다"라고 끝을 늘이면 칭찬이 아닐 수 있어요. 우리는 단어보다 말투와 상황으로 알아들어요.

자연어 처리로는

감성 분석은 텍스트가 담은 방향(긍정·부정·중립)을 봐요. 교안은 "중요한 건 얼마나와 기준"이라고 강조해요. "잘한다"와 "아주 잘한다"는 같은 긍정이어도 세기가 다릅니다.
