자연어 데이터 분석을 위한 전처리 과정 — 형태소와 말뭉치

"영화를 좋아하지 않는다"를 띄어쓰기로 자르면 "영화"를 검색해도 못 찾는다. 왜 그럴까?

"단어를 띄어쓰기로 자르면 되지 않을까? 영어가 되니 한국어도 되겠지?" 실제로는 언어마다 구조가 달라요. 한국어는 어절에 조사와 어미가 붙는 교착어라 형태소 분석이 필요합니다. 오늘은 토큰화, 불용어, 원형 찾기, 그리고 말뭉치와 사용자 사전을 차례로 봐요.

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을문장을 분석 가능한 조각(토큰)으로 자르는 법을 영어와 한국어로 비교하고, 불용어 제거와 원형 찾기(어간·표제어 추출), 한국어 형태소 분석기(KoNLPy)와 말뭉치·사용자 사전을 봅니다.
  2. 왜 중요한가자르는 방법이 검색 결과, 단어 빈도, 감성 판정을 모두 바꿔요. 특히 부정어("안·않·not")를 불용어로 지우면 뜻이 반대가 됩니다.
  3. 업무에서는사내 검색, 스팸 분류, 고객 리뷰 감성 분석, 신조어가 많은 SNS 분석에서 첫 단계로 씁니다.

처음이라면 이렇게 읽으세요. 칸마다 ① 가져갈 한 가지 → ② 일상으로 치면 → ③ 실험만 봐도 충분해요. 수식, 자세한 풀이, 업무 팁, 코드는 접어 두었어요(몰라도 됩니다).

왜 이 주제인가

자르는 자리가 다르다

영어는 공백이 단어 경계지만, 한국어 공백은 어절 단위라 뜻의 단위와 맞지 않아요.

지울 것과 지키지 말 것

불용어를 빼면 양이 줄고 핵심어가 드러나지만, "안·않·not"까지 빼면 뜻이 뒤집혀요.

사전은 늘 낡는다

"갓생", "존맛탱" 같은 신조어는 사전에 없어 엉뚱하게 잘려요. 사용자 사전을 고쳐 가야 해요.

큰 그림 — 이 회차가 흘러가는 4단계 (펼쳐 보기)

문장 → 토큰화 → 불용어 제거·원형 찾기 → 말뭉치와 사용자 사전으로 정밀도 높이기.

① 토큰화

영어: 공백 + 구두점·축약형 처리 / 한국어: 형태소 단위

② 불용어

관사·조사·접속사 제거, 부정어는 신중하게

③ 원형 찾기

어간 추출(규칙으로 자르기) 대 표제어 추출(사전의 기본형)

④ 말뭉치·사전

세종·국립국어원·모두의 말뭉치, 도메인·신조어·고유명사 사용자 사전

1토큰화

어디서 자를까 — 영어와 한국어의 토큰화

방법: 토큰화 · 형태소 분석일상: 리뷰 검색

토큰화는 문장을 의미 있는 최소 단위(토큰)로 나누는 전처리의 첫 단계예요. 토큰은 목적에 따라 단어, 형태소, 글자, 부분 단어가 될 수 있고, 어떻게 자르느냐가 뒤의 모든 결과를 바꿉니다.

이 칸에서 가져갈 한 가지

영어는 공백이 단어 경계라 비교적 쉽지만, 한국어는 어절 ≠ 형태소라서 형태소 분석기가 필요하다.

왜 이 방법을 쓰나

문제 상황

리뷰에서 "영화"라는 말을 쓴 글을 모두 찾고 싶어요.

앞 방법의 한계

띄어쓰기로 자르면 "영화를", "영화가", "영화는"이 모두 다른 토큰이 돼서 "영화"로는 못 찾아요.

해법

형태소 분석기로 "영화 + 를"처럼 뜻의 단위와 조사를 떼어 내요. 영어는 공백 기준에 구두점·축약형("don't" → do + n't)·대소문자 처리를 더합니다.

쉽게 말하면 "학교에서"를 "학교"와 "에서"로 나눠야 "학교" 칸에 넣을 수 있는 것과 같아요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

"영화를"이 있는데 "영화"로 검색하면 왜 못 찾아요?

학교 수학으로 보면 중학교 수학 집합의 "원소인가(∈)"예요. 컴퓨터는 글자가 똑같아야 같은 원소로 봐요.

공백 토큰 {나는, 이, 영화를, 좋아하지, 않는다.} 에 "영화" ∈ ? → 아니오 · 형태소 토큰 {나, 는, 이, 영화, 를, 좋아하, 지, 않, 는다} 에 "영화" ∈ ? → 예
∈"원소이다". 집합 안에 똑같은 것이 있는가
어절띄어쓰기로 나뉜 덩어리(영화를)
형태소뜻을 가진 가장 작은 단위(영화 + 를)
숫자로 한 번 해 보기영어 "I don't like this movie.": 공백 5개 → NLTK 7개(do, n't, . 분리)한국어 ①: 공백 5개 → 형태소 9개(조사·어미 4개 분리)"영화" 검색: 공백 토큰에서는 0번, 형태소 토큰에서는 1번 일치

사람 눈에는 "영화를"에 영화가 보이는데, 컴퓨터에게는 아예 다른 단어였군요!

일상으로 치면

도서관 색인 카드에 "학교에서", "학교를", "학교가"가 따로 꽂혀 있으면 "학교" 책을 다 찾기 어려워요. "학교"로 모아 꽂아야죠.

자연어 처리로는

영어 토큰화는 공백 기준에 구두점 분리, 축약형 처리, 소문자 통일을 더해요(NLTK). 한국어는 교착어라 어간에 조사·어미가 붙고 어순이 자유로워서, KoNLPy의 형태소 분석기로 먼저 형태소를 나눠야 해요. 그다음 품사 태깅으로 명사·동사·조사를 구별합니다.

박사

한국어 문장 ①에서 자르는 방법을 바꿔 보세요. "영화" 검색 결과가 어떻게 되나요?

초파리 연구원

공백으로 잘라도 "영화를"에 영화가 들어 있잖아. 그걸로 충분하지 않아?

주판봇

분석기로 자르면 "영화"가 딱 떨어지지. 검색은 내가 이긴다!

조수(하루)

분석기 결과는 교안의 NLTK·Okt 출력 그대로예요. 다른 분석기는 조금 다르게 자를 수 있어요.

실험 — 공백 대 분석기 — 같은 문장 다르게 자르기

자세한 풀이 — 영어와 한국어 전처리 비교(교안 표) (펼쳐 보기)
  1. 문자 체계: 영어는 알파벳 표음문자, 한국어는 한글(표음문자)이지만 자음·모음을 조합해요.
  2. 단어 구분: 영어는 공백으로 단어 경계가 분명하고, 한국어 공백은 어절 단위라 형태소 분석이 필요해요.
  3. 문법 구조: 영어는 어순이 비교적 고정(주어-동사-목적어), 한국어는 어순이 자유롭고 조사·어미가 문법 기능을 맡아요("나는 밥을 먹는다" ↔ "밥을 나는 먹는다").
  4. 형태: 영어는 고립어적 특성, 한국어는 어근에 접사가 붙는 교착어적 특성이에요.
  5. 품사 태깅: 영어는 NLTK의 pos_tag(NNP·VBZ 등), 한국어는 Okt의 pos(Noun·Josa 등)로 붙여요.

이 칸의 한계 · 잘라 낸 토큰에는 "이·는·the·is"처럼 흔하지만 뜻이 약한 조각이 많아요. 그대로 세면 이 조각들이 상위를 차지합니다.

업무에 쓸 때 알아 둘 것 (펼쳐 보기)

데이터 분석으로 치면

검색엔진은 형태소 분석으로 검색어와 문서를 같은 단위로 맞춰 비슷한 말까지 찾아 줘요(교안 사례: 검색 정확도 향상).

형태소 분석기도 띄어쓰기·맞춤법이 크게 틀린 글이나 신조어에서는 틀리게 자를 수 있어요(칸 ③).

교안의 파이썬 코드로 보면 (몰라도 됩니다)
tokens = word_tokenize("I don't like this movie.")영어 문장을 단어 토큰으로 나눠요 → I, do, n't, like, this, movie, .
okt = Okt(); okt.morphs("나는 이 영화를 좋아하지 않는다.")한국어 문장을 형태소로 나눠요 → 나, 는, 이, 영화, 를, 좋아하, 지, 않, 는다
okt.pos(text); okt.nouns(text)품사를 붙이고, 명사만 뽑아요.
2불용어와 원형

지울 것과 지킬 것 — 불용어 제거와 원형 찾기

방법: 불용어 제거 · 어간 추출 · 표제어 추출일상: 부정 리뷰 감성 판정

불용어는 자주 나오지만 의미 분석에 큰 도움이 안 되는 단어예요(the, is, a / 그리고, 이, 것). 빼면 양이 줄고 핵심어가 드러나요. 하지만 교안은 부정어(not, no, 안, 못)를 지우면 뜻이 왜곡된다고 경고합니다.

이 칸에서 가져갈 한 가지

불용어는 빼되 부정어는 지킨다. 원형 찾기는 규칙으로 자르는 어간 추출과 사전의 기본형을 찾는 표제어 추출 두 가지다.

왜 이 방법을 쓰나

문제 상황

리뷰에서 핵심어만 남기고, "studies·studying"처럼 모양만 다른 단어를 하나로 세고 싶어요.

앞 방법의 한계

흔한 말을 그대로 두면 분석이 무겁고 핵심어가 묻혀요. 모양이 다른 같은 단어는 따로 세어져요.

해법

불용어 목록으로 흔한 말을 빼되 부정어는 남기고, 어간 추출(running → run)이나 표제어 추출(better → good)로 원형을 맞춰요.

쉽게 말하면 회의록에서 "음, 그러니까, 일단"은 지워도 되지만 "안 됩니다"의 "안"을 지우면 결론이 뒤집혀요.

어간 추출이랑 표제어 추출은 결과가 어떻게 달라요?

학교 수학으로 보면 국어의 어간·어미, 영어의 동사 변화표(불규칙 동사)예요.

어간 추출 = 단어 − 접사(규칙으로 잘라 냄, 실제 단어가 아닐 수 있음) · 표제어 추출 = 사전에서 찾은 기본형(늘 실제 단어)
running어간 run / 표제어 run (같음)
studies어간 studi(비단어) / 표제어 study
better · was어간 better·wa / 표제어 good·be (불규칙)
숫자로 한 번 해 보기교안 문장 "I am studying natural language processing with Python and NLTK" = 10단어영어 기본 불용어 I · am · with · and 4개 제거 → 6단어(40% 감소)주의: NLTK 영어 기본 불용어 목록에는 not, no도 들어 있어요. 감성 분석이면 목록에서 빼야 해요.

규칙으로 자르는 쪽은 빠르지만 "studi" 같은 이상한 결과가 나오고, 사전을 쓰는 쪽은 느려도 진짜 단어를 주는군요.

일상으로 치면

회의록을 정리할 때 "음", "그러니까"는 지워도 되지만, "이 안건은 안 됩니다"에서 "안"을 지우면 결론이 반대가 돼요.

3말뭉치와 사전

사전은 늘 낡는다 — 말뭉치와 사용자 사전, 분석기 고르기

방법: 사용자 사전 · 말뭉치일상: SNS 신조어 리뷰

말뭉치(코퍼스)는 자연어 처리를 위해 모은 대규모 텍스트 집합이에요. 형태소 분석기는 말뭉치로 학습하고 사전으로 단어를 알아봐요. 그래서 사전에 없는 신조어는 사용자 사전으로 알려 줘야 합니다.

이 칸에서 가져갈 한 가지

분석기는 사전에 있는 말만 제대로 자른다. 신조어·전문용어·고유명사는 사용자 사전에 올리고, 미등록어를 모아 주기적으로 고친다.

왜 이 방법을 쓰나

문제 상황

SNS 리뷰에 "갓생", "존맛탱", "내돈내산" 같은 말이 많아요.

기본 사전에 없는 말은 "갓 / 생", "존 / 맛 / 탱"처럼 잘려서 빈도도 검색도 틀어져요.

해법

사용자 사전에 신조어를 올리고, 분석 목적(속도·정확도·신조어)에 맞는 분석기를 골라요. 도메인과 비슷한 말뭉치를 쓰면 정확도가 올라가요.

쉽게 말하면 새로 생긴 가게를 지도 앱에 직접 등록해야 길 찾기에 나오는 것과 같아요.

사전을 고치면 얼마나 좋아지는지 어떻게 재요?

학교 수학으로 보면 초등 수학의 비율이에요.

미등록어 비율 = 사전에 없는 단어 수 ÷ 전체 단어 수 · 명사 추출 정확도 = 올바르게 뽑힌 명사 수 ÷ 뽑혀야 할 명사 수
미등록어사전에 없어 잘못 잘릴 수 있는 단어(OOV)
뽑혀야 할 명사사람이 정한 정답 목록
주기적 갱신미등록어를 기록(로깅)해 사전에 추가
숫자로 한 번 해 보기예시 문장 단어 8개 중 신조어 3개(갓생·존맛탱·내돈내산) → 미등록어 비율 3 ÷ 8 = 37.5%사전 없이 올바른 명사 5 / 8세 단어를 사용자 사전에 올리면 8 / 8, 미등록어 0%

단어 세 개를 사전에 올렸을 뿐인데 정확도가 63%에서 100%가 되네요. 사전 관리가 곧 품질 관리군요.
