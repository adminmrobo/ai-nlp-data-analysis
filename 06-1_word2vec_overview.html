Word2Vec 개요 — 주변 단어로 단어를 배운다

"배송이 빨라요"와 "배송이 신속해요"가 같은 뜻이라는 걸 컴퓨터는 어떻게 알까?

교안은 리뷰 이야기로 시작해요. 고객은 "빨라요"와 "신속해요"처럼 표현을 다르게 해도 뜻은 같아요. Word2Vec은 "비슷한 문맥에 나오는 단어는 뜻이 비슷하다"는 분포 가설로 이를 자동으로 알아내요. 이 쪽은 그 원리, 빠르게 학습시키는 꾀, 그리고 벡터 연산을 봅니다.

분포 가설

리뷰 분석에서 "빨라요", "신속해요", "금방 와요"를 같은 칭찬으로 묶고 싶어요.

학습 원리

어휘 10만 개, 문장 수억 개로 Word2Vec을 학습시키려 해요. 단어 하나를 배울 때마다 10만 개 점수를 다 계산하면 몇 주가 걸려요.

벡터 연산

쇼핑몰에서 "남성용 운동화"를 산 고객에게 같은 스타일의 "여성용 운동화"를 추천하고 싶어요(교안 사례).

큰 그림 — 이 회차가 흘러가는 4단계 (펼쳐 보기)

분포 가설 → 학습 원리 → 벡터 연산 → 다음 쪽.

① 분포 가설

단어의 뜻은 주변 단어(문맥)로 정해진다. 같은 자리에 들어가는 단어는 벡터 공간에서 가까워진다.

② 학습 원리

전체 어휘와 매번 비교하면 계산이 어휘 수(V)에 비례한다. 네거티브 샘플링은 정답 1 + 오답 5~20개만, 계층적 소프트맥스는 log₂V번의 예·아니오만 계산한다.

③ 벡터 연산

단어 사이의 관계(성별·수도·시제)는 벡터 공간의 방향이다. 같은 방향을 더하면 관계를 옮길 수 있다. 데이터의 편향도 함께 옮겨진다.

④ 다음 쪽

300차원 단어 벡터를 사람이 눈으로 볼 수 있을까? 어떻게 2차원으로 줄일까?

1분포 가설

단어는 그 동료로 안다 — 분포 가설과 Word2Vec의 학습

방법: 분포 가설 · Word2Vec(CBOW·Skip-gram)일상: "빨라요"와 "신속해요"

교안의 예: "귀여운 강아지가 뛰어다닌다"와 "귀여운 고양이가 뛰어다닌다"에서 강아지와 고양이는 같은 자리에 들어가요. 비슷한 문맥에 나오는 단어는 비슷한 뜻을 가진다는 것이 분포 가설이고, Word2Vec은 이 패턴을 대량의 글에서 학습해요.

이 부분에서 가져갈 한 가지

단어의 뜻은 주변 단어(문맥)로 정해진다. 같은 자리에 들어가는 단어는 벡터 공간에서 가까워진다.

왜 이 방법을 쓰나

문제 상황

리뷰 분석에서 "빨라요", "신속해요", "금방 와요"를 같은 칭찬으로 묶고 싶어요.

앞 방법의 한계

원핫·TF-IDF는 단어를 글자 그대로의 기호로 다뤄요. "빨라요"와 "신속해요"는 완전히 다른 단어입니다(4회차).

해법

단어마다 주변에 어떤 단어가 오는지를 보고, 주변이 비슷한 단어끼리 벡터가 가까워지도록 학습해요.

쉽게 말하면 처음 보는 사람도 늘 같이 다니는 친구들을 보면 어떤 사람인지 짐작할 수 있죠.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

"주변 단어가 비슷하다"를 어떻게 숫자로 재요?

학교 수학으로 보면 고등학교 수학의 벡터의 내적과 코사인이에요.

단어 벡터 = 주변 단어가 나온 횟수를 부분마다 적은 것 · 유사도 = 두 벡터의 코사인 = 내적 ÷ (길이 × 길이)
문맥 창앞뒤 몇 단어까지를 "주변"으로 볼지
내적같은 자리끼리 곱해 더하기
길이√(부분마다 제곱의 합)
숫자로 한 번 해 보기앞뒤 1단어 기준 "빨라요"의 주변: 이 2번, 만족 1번, 가 1번 → (2, 1, 1)"신속해요"의 주변: 이 2번, 만족 1번, 가 0번 → (2, 1, 0)코사인 = (4 + 1 + 0) ÷ (√6 × √5) = 5 ÷ 5.48 ≈ 0.91

"자동차가 빨라요"의 "가" 하나 때문에 1이 안 되는 거네요. 그래도 0.91이면 거의 같은 뜻이에요!

일상으로 치면

회사에서 늘 마케팅팀 사람들과 점심을 먹는 신입은 아마 마케팅 업무를 하겠죠. 같이 다니는 사람을 보면 그 사람을 짐작해요.

자연어 처리로는

Word2Vec은 CBOW(주변 단어로 가운데 단어 맞히기)나 Skip-gram(가운데 단어로 주변 단어 맞히기)을 학습하는 과정에서 단어 벡터를 얻어요. ① 어휘 전체를 매번 계산하면 느려서
② 정답 단어와 일부 오답 단어(보통 5~20개)만 보는 네거티브 샘플링이나
③ 이진 트리로 계산을 O(V)에서 O(log V)로 줄이는 계층적 소프트맥스를 써요(교안).

조수(하루)

예시 문장 10개로 주변 단어를 직접 셌어요. Word2Vec은 세는 대신 맞히기를 학습해요.

실험 — 주변 단어로 비슷한 단어 찾기

자세한 풀이 — Word2Vec의 특징(교안) (펼쳐 보기)
  1. 의미적 유사성: 비슷한 문맥의 단어를 가까이 배치해요.
  2. 벡터 연산: 단어 벡터의 덧셈·뺄셈으로 관계를 추론해요("서울 − 한국 + 일본 = 도쿄").
  3. 효율적 구조: 은닉층 하나의 얕은 신경망이라 대량의 글로 빠르게 학습해요.
  4. 핵심 하이퍼파라미터: 벡터 차원(보통 100~300), 문맥 창 크기, 최소 등장 횟수, 네거티브 샘플 수.

이 부분의 한계 · 학습된 벡터는 100~300차원이라 사람이 직접 볼 수 없어요. 단어들이 정말 뜻대로 모였는지 확인하려면 2·3차원으로 줄여 그려야 해요.

업무에 쓸 때 알아 둘 것 (펼쳐 보기)

데이터 분석으로 치면

상품 리뷰로 학습한 벡터에서 "빨라요"와 가까운 단어 목록을 뽑으면 감성 사전(1회차)을 넓히는 데 쓸 수 있어요.

학습 데이터가 적으면 우연히 함께 나온 단어끼리 가까워져요. 실험의 "자동차"처럼요.

2학습 원리

Word2Vec을 빠르게 학습시키는 두 꾀 — 네거티브 샘플링과 계층적 소프트맥스

방법: 네거티브 샘플링 · 계층적 소프트맥스설정: 차원 100~300 · 윈도우 5~10 · 최소 빈도

Word2Vec은 주변 단어로 가운데 단어를 맞히며(또는 반대로) 벡터를 배워요. 그런데 매번 어휘 전체(수만~수십만 개) 중에서 정답 확률을 계산하면 너무 느려요. 교안은 두 가지 꾀를 소개해요. 정답과 오답 몇 개만 비교하는 네거티브 샘플링, 어휘를 이진 트리로 만들어 예·아니오 질문 몇 번으로 찾는 계층적 소프트맥스예요.

이 부분에서 가져갈 한 가지

전체 어휘와 매번 비교하면 계산이 어휘 수(V)에 비례한다. 네거티브 샘플링은 정답 1 + 오답 5~20개만, 계층적 소프트맥스는 log₂V번의 예·아니오만 계산한다.

왜 이 방법을 쓰나

문제 상황

어휘 10만 개, 문장 수억 개로 Word2Vec을 학습시키려 해요. 단어 하나를 배울 때마다 10만 개 점수를 다 계산하면 몇 주가 걸려요.

앞 방법의 한계

기본 방식(소프트맥스)은 "정답 단어일 확률"을 내려고 어휘 전체의 점수를 매번 계산해요. 계산량이 어휘 수에 비례(O(V))해요.

해법

네거티브 샘플링은 정답 단어 1개와 무작위 오답 5~20개만 구분하게 해요. 계층적 소프트맥스는 단어를 트리의 잎에 두고 갈림길 질문 log₂V번으로 확률을 계산해요.

쉽게 말하면 10만 명 중 범인을 찾을 때 전원을 조사하지 않고, 진짜 용의자 1명과 무작위 몇 명만 비교하거나(네거티브), "남자예요? 서울 살아요?" 스무고개로 좁히는 거예요(계층적).

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

O(V)가 O(log V)가 된다는 게 무슨 뜻이에요?

학교 수학으로 보면 로그(고등학교) — 2를 몇 번 곱해야 그 수가 되나

계층적 소프트맥스 계산 수 ≈ log₂V
V어휘 수
O(V)계산이 어휘 수에 비례해 늘어남
log₂V반씩 나누는 질문을 몇 번 하면 하나가 남나
숫자로 한 번 해 보기V = 1,024 = 2¹⁰ → 10번V = 100,000 ≈ 2¹⁷ → 약 17번V가 100배 늘어도 질문은 약 7번 늘 뿐

어휘가 아무리 커져도 질문 수는 조금씩만 느는 거네요. 업다운 숫자 맞히기 게임이랑 같아요!

일상으로 치면

10만 명을 한 명씩 다 확인하면 10만 번이지만, 예·아니오 스무고개라면 17번이면 충분해요(2¹⁷ ≈ 13만).

자연어 처리로는

네거티브 샘플링: 모든 단어 대신 대상 단어와 부정 샘플 몇 개(보통 5~20개)만 학습해 대규모 어휘에서도 효율적이에요. 계층적 소프트맥스: 이진 트리로 계산 복잡도를 O(V)에서 O(log V)로 줄여요. 핵심 하이퍼파라미터: 벡터 차원(100~300), 윈도우 크기(주변 단어 범위, 보통 5~10), 최소 단어 빈도, 학습률(교안).

조수(하루)

"계산 수"는 단어 하나를 학습할 때 확률을 매기는 단어(또는 갈림길)의 수로 단순화한 비교예요.

실험 — 단어 하나 학습할 때의 계산 수 비교

자세한 풀이 — Word2Vec의 학습 원리(교안) (펼쳐 보기)
  1. 학습 목표: 주변 단어(윈도우 안)로 가운데 단어를 맞히거나(CBOW), 가운데 단어로 주변 단어를 맞히며(Skip-gram) 벡터를 조정해요.
  2. 네거티브 샘플링: 모든 단어 대신 정답과 부정 샘플 몇 개(5~20)만 학습해 대규모 어휘에서도 효율적이에요.
  3. 계층적 소프트맥스: 이진 트리의 갈림길마다 예·아니오를 정해 단어를 예측, 계산량 O(V) → O(log V).
  4. 하이퍼파라미터: 차원 100~300, 윈도우 5~10, 최소 단어 빈도(드문 단어 거르기), 학습률.

이 부분의 한계 · 빨리 배운 벡터로 무엇을 할 수 있을까요? 벡터끼리 더하고 빼면 뜻의 관계가 계산돼요. 다음 부분이에요.

업무에 쓸 때 알아 둘 것 (펼쳐 보기)

데이터 분석으로 치면

사내 데이터로 Word2Vec을 학습할 때는 차원·윈도우·최소 빈도 설정을 기록해 두면 결과를 재현하고 비교할 수 있어요.

데이터가 적으면 사전 학습 벡터를 가져오는 편이 나아요.

3벡터 연산

관계는 방향이다 — 벡터 연산과 시각화

방법: 벡터 연산 · PCA · t-SNE일상: 왕과 여왕, 서울과 도쿄

Word2Vec 벡터에서는 "왕 − 남자 + 여자 ≈ 여왕"처럼 관계가 일정한 방향으로 놓여요. 300차원을 2차원에 그리려면 PCA(분산이 큰 방향으로 투영)나 t-SNE(가까운 점은 가깝게 유지) 같은 차원 축소가 필요하고, 그려 보면 편향도 드러나요.

이 부분에서 가져갈 한 가지

단어 사이의 관계(성별·수도·시제)는 벡터 공간의 방향이다. 같은 방향을 더하면 관계를 옮길 수 있다. 데이터의 편향도 함께 옮겨진다.

왜 이 방법을 쓰나

문제 상황

쇼핑몰에서 "남성용 운동화"를 산 고객에게 같은 스타일의 "여성용 운동화"를 추천하고 싶어요(교안 사례).

앞 방법의 한계

단어 목록만으로는 "남성용 ↔ 여성용" 같은 관계를 옮길 수 없어요.

해법

벡터 연산: 남성용 운동화 − 남성 + 여성. 관계가 일정한 방향이라 결과 근처에서 여성용 상품을 찾아요.

쉽게 말하면 지도에서 "집 → 회사" 화살표를 그대로 옮겨 "친구 집"에서 출발하면 친구 회사 근처에 닿는 것과 같아요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

벡터를 빼고 더한다는 게 그림에서 무슨 뜻이에요?

학교 수학으로 보면 고등학교 수학의 벡터의 덧셈과 뺄셈(평행이동)이에요.

결과 = vec(왕) − vec(남자) + vec(여자) → 결과와 가장 가까운 단어 찾기
vec(여자) − vec(남자)"남자 → 여자" 방향 화살표(성별 관계)
vec(왕) + 그 화살표왕을 같은 방향으로 옮기기
가장 가까운 단어계산한 점과 거리가 가장 짧은 단어
숫자로 한 번 해 보기예시 좌표: 왕 (4, 1.4), 남자 (1, 1), 여자 (1, 3.2)왕 − 남자 + 여자 = (4 − 1 + 1, 1.4 − 1 + 3.2) = (4, 3.6)여왕 (4.1, 3.5)까지 거리 = √(0.1² + 0.1²) ≈ 0.14 → 가장 가까운 단어는 여왕

화살표를 평행이동한 거였네요! 그런데 같은 계산으로 "간호사"가 나오는 건 위험하겠어요.

일상으로 치면

"우리 집에서 회사까지" 화살표를 친구 집에 그대로 옮기면 친구 회사 근처에 닿아요. 동네마다 길이 조금 달라 정확히 맞지는 않죠.

자연어 처리로는

벡터 공간에서 성별·시제·비교급 같은 관계는 특정 방향으로 나타나요. PCA는 계산이 빠르고 전체 구조를 보존하지만 비선형 관계에 약하고, t-SNE는 가까운 이웃 구조를 잘 지켜 군집을 선명하게 보여 줘요(perplexity 보통 5~50, 단어 벡터에는 30~50). 시각화로 동물·색상·감정 단어의 군집과 함께 "간호사-여성, 엔지니어-남성" 같은 편향도 발견돼요(교안).

실험 — 벡터 덧셈·뺄셈으로 관계 옮기기

자세한 풀이 — 단어 임베딩 공간과 시각화(교안) (펼쳐 보기)
  1. 고차원 공간: 단어 벡터는 보통 100~300차원, 각 차원은 잠재적 의미 특성이지만 하나하나의 뜻은 해석하기 어려워요(분산 표현).
  2. 군집: 동물(고양이·개·말), 감정(기쁨·슬픔), 지명(서울·뉴욕·파리)이 각각 모여요.
  3. PCA: 데이터 중앙화 → 공분산 행렬 → 고유값·고유벡터 → 주성분 선택 → 투영.
  4. t-SNE: 국소 구조를 보존해 의미 군집을 선명하게 보여 줘요. 도구로는 웹 기반 시각화, 3D, VR·AR 탐색도 시도되고 있어요.
  5. 편향 점검: "간호사-여성", "엔지니어-남성"처럼 학습 데이터의 사회적 편향이 벡터에 남아요.

정리

부분새로 생긴 능력남은 한계
① 분포 가설단어의 뜻은 주변 단어(문맥)로 정해진다. 같은 자리에 들어가는 단어는 벡터 공간에서 가까워진다.벡터가 300차원이라 사람이 직접 볼 수 없음
② 학습 원리전체 어휘와 매번 비교하면 계산이 어휘 수(V)에 비례한다. 네거티브 샘플링은 정답 1 + 오답 5~20개만, 계층적 소프트맥스는 log₂V번의 예·아니오만 계산한다.학습이 빨라져도 데이터에 없던 단어(OOV)는 여전히 벡터가 없음
③ 벡터 연산단어 사이의 관계(성별·수도·시제)는 벡터 공간의 방향이다. 같은 방향을 더하면 관계를 옮길 수 있다. 데이터의 편향도 함께 옮겨진다.거리를 재는 방법에 따라 "가깝다"의 판단이 달라짐
