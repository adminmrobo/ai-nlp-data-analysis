6회차 · 원 강의 5회차

Word2Vec 활용

"배송이 빨라요"와 "배송이 신속해요"가 같은 뜻이라는 걸 컴퓨터는 어떻게 알까?

6-1 · Word2Vec 개요
  1. 단어의 뜻은 주변 단어(문맥)로 정해진다. 같은 자리에 들어가는 단어는 벡터 공간에서 가까워진다.
  2. 전체 어휘와 매번 비교하면 계산이 어휘 수(V)에 비례한다. 네거티브 샘플링은 정답 1 + 오답 5~20개만, 계층적 소프트맥스는 log₂V번의 예·아니오만 계산한다.
  3. 단어 사이의 관계(성별·수도·시제)는 벡터 공간의 방향이다. 같은 방향을 더하면 관계를 옮길 수 있다. 데이터의 편향도 함께 옮겨진다.

남은 한계: 거리를 재는 방법에 따라 "가깝다"의 판단이 달라짐

6-2 · 단어 벡터의 시각화
  1. 임베딩 공간에서는 거리가 뜻의 가까움, 방향이 관계를 나타낸다. 시각화는 이 군집과 방향을 눈으로 확인하는 도구다.
  2. PCA는 점들이 가장 길게 퍼진 방향(주성분)으로 그림자를 만들어 차원을 줄인다. 전체 구조는 잘 남기지만 휘어진 구조와 작은 이웃 관계는 잃는다.
  3. 전체 모양은 PCA, 이웃 군집은 t-SNE로 본다. 그리고 그림 속 가까움은 데이터가 만든 것이라 사회적 편향까지 함께 배운다.

남은 한계: t-SNE 그림의 군집 간 거리·크기는 그대로 해석하기 어렵고, 편향은 시각화로 찾아도 따로 고쳐야 함

6-3 · 단어의 유사도 측정
  1. 유사도는 "얼마나 비슷한가"를 0~1 사이 숫자로 말해 준다. 단어 벡터에서는 보통 0.7 이상이면 높은 유사도, 0.3 이하면 낮은 유사도로 본다.
  2. 거리는 벡터의 길이에 흔들리고, 코사인은 방향만 본다. 자주 쓰여 길어진 단어도 뜻(방향)으로 비교하려면 코사인.
  3. 데이터 모양에 맞는 자를 고른다. 벡터 방향은 코사인, 태그·키워드 집합은 자카드, 확률 분포는 KL(비대칭 주의). Word2Vec의 미등록어·다의어 문제는 FastText·BERT가 푼다.

남은 한계: 단어 하나에 벡터 하나 — 문맥마다 뜻이 바뀌는 단어를 못 담음

7회차 · 원 강의 6회차

텍스트 생성: 기본

"가격이 저렴하다"와 "가성비가 좋다"를 같은 뜻으로 알아보고, 리뷰를 자동으로 분류하는 모델은 어떻게 만들고 평가할까?

7-1 · 분류·회귀와 평가
  1. 결과가 "어느 칸"이면 분류, "몇 점"이면 회귀다. 문제를 먼저 정해야 모델과 평가 지표(정확도·F1 대 MAE·RMSE·R²)가 정해진다.
  2. 로지스틱 회귀는 "단어 점수의 합"을 시그모이드로 눌러 확률로 만든다. 합이 0이면 50%, 클수록 100%에 가까워진다.
  3. 불균형 데이터에서는 정확도만 보면 속는다. 잡아야 할 것을 얼마나 잡았나(재현율)와 잡은 것 중 진짜는 얼마나(정밀도)를 함께, F1로 본다.

남은 한계: 단어를 한꺼번에 넣는 모델(TF-IDF + 로지스틱 회귀)은 단어 순서를 기억하지 못함

7-2 · RNN과 LSTM
  1. 뉴런은 "가중합 → 활성화 함수" 두 동작뿐이다. 이 단순한 계산을 층층이 쌓으면 복잡한 패턴을 배운다. 활성화 함수가 없으면 아무리 쌓아도 일차함수 하나와 같다.
  2. RNN은 매 단계 기억에 같은 계수를 곱하며 넘긴다. 계수가 1보다 작으면 기억이 거듭제곱으로 사라지고(소실), 1보다 크면 폭발한다(폭주). 그래서 10~20단계 넘는 관계를 배우기 어렵다.
  3. RNN은 걸음마다 정보를 조금씩 잃어 긴 문장의 앞부분을 잊는다(기울기 소실). LSTM은 셀 상태와 세 게이트로 필요한 정보를 오래 지킨다.

남은 한계: 문장을 한 단어씩 읽어 길이만큼 걸음이 필요하고, 문장을 만들어 내지는 못함

7-3 · Seq2Seq와 텍스트 생성
  1. Seq2Seq = 읽기(인코더) → 한 벡터로 요약(문맥 벡터) → 한 단어씩 쓰기(디코더). 앞에서 쓴 단어가 다음 단어의 입력이 된다.
  2. Seq2Seq는 문장 전체를 고정 크기 벡터 하나에 압축한다. 문장이 길수록 앞부분이 흐려지는 정보 병목이 생긴다.
  3. BLEU는 정답 번역과 1~4단어 묶음이 얼마나 겹치는지(정밀도)의 평균에, 너무 짧은 번역을 깎는 간결성 페널티를 곱한 점수다. 겹침을 보지 뜻을 보지 않는다.

남은 한계: BLEU는 같은 뜻의 다른 표현(동의어·어순)을 낮게 매길 수 있음

8회차 · 원 강의 7회차

텍스트 생성: 고급

Seq2Seq는 왜 긴 문장에서 앞부분을 잊고, 같은 말을 반복할까? 무엇으로 고칠 수 있을까?

8-1 · Seq2Seq의 한계와 개선
  1. 자연어 모델의 발전은 "고정 벡터(Seq2Seq) → 필요할 때마다 다시 보기(어텐션) → 어텐션만으로 병렬 처리(트랜스포머) → 거대 사전학습·프롬프트"의 순서다.
  2. 매 순간 1등만 고르는 탐욕적 선택은 문장 전체로 손해일 수 있다. 빔 서치는 후보 몇 개를 남겨 문장 전체 확률이 높은 길을 찾는다.
  3. 문제마다 처방이 다르다. 정보 병목 → 어텐션, 기울기 소실 → 잔차 연결, 학습 불안정 → 층 정규화, 반복·누락 → 빔 서치 + 커버리지. 벡터 크기만 키우는 건 근본 해결이 아니다.

남은 한계: 어텐션을 붙여도 RNN의 순차 처리(느림)는 남음

8-2 · 어텐션 메커니즘
  1. 어텐션 = Query와 각 Key의 닮음(내적) → 소프트맥스로 비율(합 1) → 그 비율로 Value를 섞은 문맥 벡터. 출력 단어마다 비율이 새로 계산된다.
  2. 어텐션 = 지금 만들 단어(Q)와 원문 단어(K)의 점수 → 소프트맥스로 가중치 → 원문 내용(V)의 가중 평균. 단어마다 다른 문맥 벡터가 생긴다.
  3. 어텐션은 번역 품질을 높일 뿐 아니라 "어느 원문 단어를 보고 이 단어를 썼는지"를 히트맵으로 보여 준다. 히트맵은 오류 진단에 쓴다.

남은 한계: 히트맵은 집중을 보여 줄 뿐, 번역의 옳고 그름을 직접 판정하지는 않음

8-3 · 트랜스포머
  1. 트랜스포머의 한 층 = (멀티헤드) 셀프 어텐션 → 잔차+층 정규화 → 피드포워드 → 잔차+층 정규화. 순서는 입력에 더한 위치 신호(포지셔널 인코딩)로 안다.
  2. 셀프 어텐션은 문장 안 모든 단어 쌍의 관계를 한 번에 계산한다. 그래서 병렬 계산이 되고, 먼 단어의 단서로 뜻을 정한다. 순서는 위치 정보로 더한다.
  3. 포지셔널 인코딩은 위치마다 고유한 "물결 무늬 번호표"다. 빠른 물결과 느린 물결을 섞어, 가까운 순서와 먼 순서를 모두 구별한다.

남은 한계: 고정된 물결이라 학습 때 본 것보다 아주 긴 문장에는 약할 수 있음

9회차 · 원 강의 8회차

최신 인공지능 언어모델

같은 트랜스포머로 만든 GPT와 BERT는 무엇이 다르고, 어떤 일에 어느 모델을 써야 할까?

9-1 · 최신 언어모델 개요
  1. 규칙 기반은 정해진 문법 안에서만, 딥러닝 언어모델은 데이터에서 배운 패턴으로 문맥을 이해한다. GPT는 커질수록 Few-shot·추론·멀티모달 같은 새 능력을 보였다.
  2. GPT는 앞 문맥만 보고 다음 단어를 이어 써서 생성에 강하고, BERT는 빈칸 앞뒤를 다 보고 맞혀서 분류·이해에 강하다.
  3. 생성은 GPT, 이해·분류는 BERT 계열, 여러 작업을 한 형식으로는 T5, 글+이미지는 CLIP·DALL-E. 일의 성격이 모델을 고른다.

남은 한계: 모델을 골라도 우리 데이터·업무에 맞추는 과정이 남음(→ 전이학습)

9-2 · 전이학습과 프롬프트
  1. 전이학습 = 일반 언어 능력(사전훈련)을 빌려 와 우리 일에만 조금 더 가르치기(미세조정). 대신 사전훈련 데이터의 편향도 함께 옮겨 온다.
  2. Hugging Face는 "모델 가게(Model Hub) + 같은 사용법(Transformers)"이다. 모델을 바꿔도 코드 모양이 거의 같아 실험이 빠르다.
  3. 모델을 처음부터 만들지 않는다. 사전훈련 모델을 데이터로 맞추거나(파인튜닝), 지시문으로 맞춘다(프롬프트). 형식을 정해 주면 결과를 모아 쓸 수 있다.

남은 한계: 모델이 모르는 최신·사내 정보는 프롬프트로도 만들어 낼 수 없음(할루시네이션 위험)

9-3 · LLM과 RAG
  1. LLM은 하나의 모델로 여러 일을 하는 "넓은 AI"이고, 커지면서 새 능력이 나타난다. 하지만 학습 시점 이후 정보와 우리 회사 데이터는 모른다.
  2. 도메인 특화는 두 계단이다. ① 그 분야 글을 많이 읽혀 말귀를 트이게 하고(도메인 적응) ② 할 일을 가르친다(태스크별 미세조정). 그리고 품질을 계속 재고 고친다.
  3. LLM은 우리 회사 규정과 최신 정보를 모른다. 질문과 가까운 문서를 벡터 검색으로 찾아 함께 넣으면(RAG) 근거를 밝힌 답을 얻는다.

남은 한계: 검색이 엉뚱한 문서를 가져오면 답도 틀림, 사람의 확인이 계속 필요

6회차 · 두 단어 벡터의 코사인 유사도 (6-3쪽)

단어 A의 벡터는 (1, 2, 2), 단어 B의 벡터는 (2, 1, 2)예요. 코사인 유사도는? (소수 둘째 자리)

  1. 내적 = 1×2 + 2×1 + 2×2 = 8
  2. |A| = √(1 + 4 + 4) = 3, |B| = √(4 + 1 + 4) = 3
  3. 코사인 = 8 ÷ (3 × 3) ≈ 0.89

초파리의 흔한 실수 · 내적 8을 그대로 답하면 길이로 나누지 않은 값이에요. 코사인은 늘 −1~1 사이예요.

업무에서는 · 0.7 이상이면 높은 유사도(교안 기준). 검색어 확장 후보로 쓸 수 있어요. (숫자는 예시값)

7회차 · 스팸 필터의 F1 점수 (7-1쪽)

스팸 필터의 정밀도가 75%, 재현율이 60%예요. F1 점수는 몇 %? (소수 첫째 자리)

%

  1. F1 = 2 × 정밀도 × 재현율 ÷ (정밀도 + 재현율)
  2. = 2 × 0.75 × 0.60 ÷ (0.75 + 0.60) = 0.90 ÷ 1.35
  3. ≈ 0.667 → 66.7%

초파리의 흔한 실수 · 두 값의 산술평균 (75 + 60) ÷ 2 = 67.5%는 F1이 아니에요. 조화평균은 낮은 쪽에 더 끌려가요.

업무에서는 · 불균형 데이터에서는 정확도 대신 F1로 모델을 비교해요(7회차). (숫자는 예시값)

8회차 · 소프트맥스 어텐션 가중치 (8-2쪽)

원문 단어 세 개의 어텐션 점수가 (1, 0, 0)이에요. 소프트맥스로 바꾼 첫 단어의 가중치는 몇 %? (e ≈ 2.718, 소수 첫째 자리)

%

  1. e¹ ≈ 2.718, e⁰ = 1, e⁰ = 1
  2. 합 = 2.718 + 1 + 1 = 4.718
  3. 2.718 ÷ 4.718 ≈ 0.576 → 57.6%

초파리의 흔한 실수 · 점수 비율 1 ÷ (1 + 0 + 0) = 100%로 계산하면 소프트맥스가 아니에요. 지수를 씌운 뒤 나눠요.

업무에서는 · 점수 차가 작으면 가중치가 고르게 퍼져요. 히트맵이 흐릿하면 모델이 주목할 곳을 못 찾은 거예요(8회차). (숫자는 예시값)

9회차 · RAG 문서 검색 유사도 (9-3쪽)

질문의 키워드는 4개, 어떤 문서의 키워드는 9개이고 둘이 겹치는 키워드가 3개예요(키워드마다 1번씩). 키워드 벡터의 코사인 유사도는? (소수 둘째 자리)

  1. 내적 = 겹치는 키워드 수 = 3
  2. |질문| = √4 = 2, |문서| = √9 = 3
  3. 코사인 = 3 ÷ (2 × 3) = 0.50

초파리의 흔한 실수 · 3 ÷ 4 = 0.75(질문 중 겹친 비율)는 코사인이 아니에요. 두 벡터의 길이로 함께 나눠요.

업무에서는 · RAG는 이렇게 질문과 가까운 문서를 골라 LLM에 함께 넣어요. 실제로는 임베딩 벡터로 계산해요(9회차). (숫자는 예시값)
