인공지능과 자연어 데이터 분석 — 말을 "알아듣는" 기계

"소리를 듣는다"와 "말귀를 알아듣는다"는 무엇이 다를까? 기계가 말을 알아들으려면 무엇이 필요할까?

"알아듣다"는 소리를 인식하는 것을 넘어 뜻을 파악하는 일이에요. 인공지능은 판단과 인식 두 능력으로 발전해 왔고, 그 방식은 사람이 쓴 규칙에서 데이터로 배운 기준으로 바뀌었어요. 오늘은 말과 글이라는 특별한 데이터를 기계가 어떻게 다루기 시작하는지 봅니다.

판단 + 인식교안이 꼽은 AI의 두 능력
80.3% → 82.4%실험: 전문가 규칙 → 데이터로 찾은 기준(새 신청자 정확도)
3방향감성 분석: 긍정 · 부정 · 중립
9 / 10실험: 규칙 둘을 더한 감성 사전이 맞힌 리뷰
박사

오늘은 기계가 말을 "듣는" 데서 "알아듣는" 데까지 가는 길을 걸어요.

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을AI가 판단하는 두 방식(사람이 쓴 규칙, 데이터에서 찾은 기준)을 비교하고, 말과 글이 표(정형 데이터)와 어떻게 다른지, 회사가 리뷰와 여론을 어떻게 분석하는지 봅니다.
  2. 왜 중요한가말과 글은 회사 데이터의 큰 부분이지만 표처럼 칸이 정해져 있지 않아요. 무엇이 어려운지 알아야 2회차부터 나오는 도구가 왜 필요한지 보입니다.
  3. 업무에서는고객 리뷰·문의(VOC) 분석, 뉴스·SNS 여론 모니터링, 기계 번역, 챗봇과 ChatGPT 활용에 씁니다.

처음이라면 이렇게 읽으세요. 칸마다 ① 가져갈 한 가지 → ② 일상으로 치면 → ③ 실험만 봐도 충분해요. 수식, 자세한 풀이, 업무 팁, 코드는 접어 두었어요(몰라도 됩니다).

1규칙과 학습

대출 심사 기준은 누가 정하나 — 규칙 기반과 머신러닝

방법: 규칙 기반 · 머신러닝일상: 신용대출 심사

교안은 신용대출 순서도를 예로 들어요. 소득, 카드 지출, 직업 같은 조건을 예·아니오로 따라가는 방식이 규칙 기반이에요. 같은 조건을 과거 데이터에서 알고리즘이 스스로 찾으면 머신러닝입니다.

이 칸에서 가져갈 한 가지

규칙 기반은 사람이 조건을 쓰고, 머신러닝은 과거 데이터에서 조건을 찾는다. 그래서 머신러닝에는 데이터가 필요하다.

왜 이 방법을 쓰나

문제 상황

대출 신청이 하루 수천 건 들어와요. 누구에게 빌려줄지 일관된 기준이 필요합니다.

앞 방법의 한계

예전에는 은행 전문가가 경험으로 "소득은 이만큼, 카드 지출은 이만큼"을 정했어요. 조건이 많아지면 사람이 모든 조합을 써 내기 어렵습니다.

해법

제때 갚은 사람과 못 갚은 사람의 지난 기록을 주고, 두 무리를 가장 잘 나누는 기준을 알고리즘이 찾게 해요.

쉽게 말하면 선배의 감을 받아 적는 대신, 지난 심사 기록 수백 건을 펼쳐 놓고 갈림길을 찾는 거예요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

데이터로 "기준을 찾는다"는 게 정확히 뭘 계산하는 거예요?

학교 수학으로 보면 중학교 수학의 부등식과 비율이에요.

승인 ⇔ 월소득 ≥ T₁ 그리고 카드지출 비율 ≤ T₂ · 정확도 = 맞게 판정한 사람 수 ÷ 전체
T₁, T₂승인 기준이 되는 두 문턱값
≥, ≤이상, 이하. 부등식으로 쓴 규칙
정확도판정과 실제 결과(갚음·연체)가 같은 비율
숫자로 한 번 해 보기전문가 규칙: T₁ = 300만 원, T₂ = 60%데이터 기준: T₁은 25만 원, T₂는 4%p 간격으로 바꿔 가며 지난 200건에서 정확도가 가장 높은 조합을 고름 → T₁ = 325만 원, T₂ = 70%새 신청자 1,000명 정확도: 전문가 규칙 80.3%, 데이터 기준 82.4%

조건의 모양(부등식)은 같고, 문턱값을 사람이 정하느냐 데이터가 정하느냐의 차이였네요!

일상으로 치면

신입 심사역은 선배의 감(규칙)을 배우기도 하고, 지난 몇 년의 심사 기록을 보며 스스로 감을 잡기도 해요.

자연어 처리로는

규칙 기반은 개발자가 전문가에게 들은 조건을 코딩해요(규칙 설계 → 코딩 → 테스트). 머신러닝은 데이터 수집 → 모델 학습 → 검증 → 최적화로 기준을 만들고, 처음 보는 신청자에게도 학습한 패턴으로 판정합니다. 대신 데이터가 적거나 치우치면 기준도 틀어져요.

박사

먼저 슬라이더로 전문가 규칙의 승인 칸을 정해 보세요. 그다음 "데이터로 찾은 기준"을 눌러 비교해요.

주판봇

데이터가 찾은 기준이 무조건 이기지!

초파리 연구원

지난 기록이 200건뿐이잖아. 처음 보는 신청자에게도 맞는지 봐야지.

조수(하루)

정확도는 기준을 찾는 데 쓰지 않은 새 신청자 1,000명으로 쟀어요. 데이터는 시드를 고정한 설명용 모형이에요.

실험 — 전문가 규칙 대 데이터로 찾은 기준

자세한 풀이 — 규칙 기반과 머신러닝(교안 비교표) (펼쳐 보기)
  1. 문제 해결 방식: 규칙 기반은 명시적 규칙, 머신러닝은 데이터 기반 패턴 학습이에요.
  2. 프로그램 작성: 규칙 기반은 개발자가 모든 규칙을 정의하고, 머신러닝은 알고리즘이 데이터로부터 학습해요.
  3. 잘 푸는 문제: 규칙 기반은 규칙이 분명한 문제, 머신러닝은 복잡하고 변하는 패턴의 문제예요.
  4. 적응과 예측: 규칙 기반은 프로그래밍된 규칙 안에서만, 머신러닝은 학습한 패턴으로 새 상황도 예측해요.
  5. 필요한 것: 규칙 기반에는 전문가가, 머신러닝에는 데이터가 필요해요. 데이터의 중요성이 커진 이유입니다.

이 칸의 한계 · 교안의 "치와와 대 머핀" 사진처럼 점 세 개·흰 부분·갈색 같은 특징을 사람이 정해서 나누는 방식은 쉽게 헷갈려요. 두 살 아이는 규칙 없이 익숙한 패턴으로 알아보죠. 이 "인식"을 흉내 낸 것이 신경망·딥러닝(7회차)입니다.

업무에 쓸 때 알아 둘 것 (펼쳐 보기)

데이터 분석으로 치면

신용평가, 이상 거래 탐지처럼 "예·아니오" 판단이 반복되는 업무에서 규칙과 학습을 함께 써요. 규칙은 설명하기 쉽고, 학습은 사람이 놓친 패턴을 찾아요.

실제 대출 심사는 법·규제상 설명할 수 있는 기준이 필요해 두 방식을 섞는 경우가 많아요. 이 실험의 두 변수 모형은 원리를 보이려는 단순화입니다.

2자연어 데이터

표와 무엇이 다른가 — 자연어 데이터의 특징

개념: 정형 · 비정형 데이터 · 형태소일상: 편의점 발주표 대 고객 리뷰

편의점 발주 목록표처럼 칸이 정해진 표가 정형 데이터예요. 이메일, SNS, 뉴스, 리뷰, 음성, 영상은 칸이 없는 비정형 데이터이고, 그 많은 부분이 말과 글(자연어)입니다.

이 칸에서 가져갈 한 가지

자연어는 칸이 없는 데이터다. 그래서 분석 전에 문장 → 어절 → 형태소로 쪼개고, 뜻이 있는 조각만 고르는 일이 먼저다.

왜 이 방법을 쓰나

문제 상황

"고객이 우리 제품을 어떻게 생각하나"를 알고 싶은데, 데이터는 리뷰 글이에요.

앞 방법의 한계

엑셀·SQL·통계는 행과 열이 정해진 표를 전제로 해요. 글에는 그런 칸이 없습니다.

해법

글을 분석 단위(문장 → 어절 → 형태소)로 쪼개고, 조사·어미처럼 뜻이 약한 조각을 빼서 셀 수 있는 모양으로 만들어요.

쉽게 말하면 긴 영수증을 품목 줄로 잘라 품목별로 세는 것과 비슷해요.

문장 ⊃ 어절(띄어쓰기 단위) ⊃ 형태소(뜻을 가진 가장 작은 단위) · 분석에 쓰는 조각 = {형태소} − {조사·어미}
⊃포함한다. 문장 안에 어절이, 어절 안에 형태소가 있음
형태소"갔다" = 가(가다) + 았(과거) + 다(끝맺음)
−집합에서 빼기. 문법 기능만 하는 조각을 덜어 냄

"는", "에"는 글에는 꼭 필요하지만 "무엇에 대한 글인가"를 셀 때는 도움이 안 되는구나!

3감성 분석

이 리뷰는 좋다는 말일까 — 감성 분석과 비즈니스 활용

방법: 감성 사전(규칙) 기반 감성 분석일상: 쇼핑몰 리뷰 · 고객의 소리(VOC)

교안은 감성 분석을 "이 글이 좋은 말이냐, 나쁜 말이냐"로 소개해요. 긍정·부정에, 판단을 보류하거나 정보만 주는 중립을 더해 세 방향으로 나눕니다. 먼저 긍정·부정 단어 사전으로 점수를 매기는 규칙 방식부터 해 봐요.

이 칸에서 가져갈 한 가지

감성 사전(규칙)은 빠르고 설명하기 쉽지만 부정어·신조어·비꼬는 말에서 틀린다. 규칙을 끝없이 더하는 대신 데이터로 배우는 쪽으로 넘어간다.

왜 이 방법을 쓰나

문제 상황

리뷰가 하루 수천 건, 댓글은 100만 건이 쌓여요. 사람이 하나하나 읽을 수 없어요.

앞 방법의 한계

단어 몇 개만 세면 "좋지 않아요"(좋다 + 부정)를 긍정으로 착각해요.

해법

교안의 순서대로 정규화 → 토큰화 → 불용어 제거로 다듬은 뒤, 긍정 단어(좋다·추천)와 부정 단어(실망·불만족) 사전으로 점수를 더해요. 부정어·신조어 규칙을 더해 보완합니다.

쉽게 말하면 채점표를 들고 리뷰를 훑으며 칭찬 단어에 +, 불평 단어에 −를 매기는 거예요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

"나쁘지 않아요"에는 나쁘다(−1)가 있는데 왜 긍정이에요?

학교 수학으로 보면 중학교 수학의 정수의 덧셈과 부호예요.

리뷰 점수 = Σ 단어 점수 (부정어가 오면 바로 앞 단어 점수의 부호를 뒤집음) · 점수 > 0 → 긍정, < 0 → 부정, = 0 → 중립
Σ모두 더하기
부호 뒤집기−1 → +1. "않·안·못"이 앞말을 부정
= 0감성 단어가 없거나 서로 상쇄되면 중립
숫자로 한 번 해 보기"좋지 않아요, 실망입니다": 좋(+1) → 않(뒤집기, −1) → 실망(−1) = −2 → 부정 ✓부정어 규칙이 없으면: 좋(+1) + 실망(−1) = 0 → 중립 ✗"나쁘지 않아요": 나쁘(−1) → 않(뒤집기) = +1 → 긍정 ✓

뒤집기 규칙 하나로 두 리뷰가 바로 맞았어요. 그런데 "참 빨리도 오네요 ^^"는요…?
