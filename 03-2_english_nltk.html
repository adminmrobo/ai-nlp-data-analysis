1NLTK 소개

NLTK — 영어 자연어 처리의 교과서 같은 도구

도구: NLTK(Natural Language Toolkit)쓰임: 교육 · 프로토타이핑 · 전처리

NLTK는 스티븐 버드(Steven Bird)와 에드워드 로퍼(Edward Loper)가 교육용으로 만든 대표적인 파이썬 자연어 처리 패키지예요. 토큰화·품사 태깅부터 구문 분석, 워드넷(WordNet) 의미 분석, 텍스트 분류, 말뭉치 관리까지 한 상자에 들어 있어요.

이 칸에서 가져갈 한 가지

NLTK는 50개가 넘는 말뭉치·어휘 자원과 친절한 문서를 갖춘 "배우고 시험해 보는" 도구다. 대량·실시간 서비스에는 다른 도구를 함께 검토한다.

왜 이 방법을 쓰나

문제 상황

영어 리뷰를 분석하려는데 토큰화, 품사 붙이기, 불용어 목록, 단어 사전을 모두 따로 구하기 막막해요.

앞 방법의 한계

기능마다 다른 도구를 쓰면 결과 형식이 제각각이라 이어 붙이기 어렵고, 처음 배우는 사람은 어디서 시작할지 몰라요.

해법

NLTK 하나로 전처리부터 분류까지 같은 방식으로 이어 가요. 말뭉치와 예제가 들어 있어 바로 실습할 수 있어요.

쉽게 말하면 요리를 처음 배울 때 재료와 레시피가 함께 든 밀키트로 시작하는 것과 같아요.

일상으로 치면

밀키트에는 손질한 재료, 소스, 레시피 카드가 함께 들어 있어 처음 요리하는 사람도 따라 할 수 있어요. 식당 대량 조리에는 다른 장비가 필요하지만요.

자연어 처리로는

NLTK의 특징: 50개 이상의 말뭉치와 어휘 자원, 직관적인 사용법과 자세한 문서, 사용자 정의 모델로 확장, 활발한 커뮤니티, 다른 파이썬 데이터 과학 라이브러리와의 호환. 교육 분야(NLP 강의 자료, 언어학 연구, 실습·시각화)와 실무 분야(시제품, 전처리, 감정 분석, 주제 모델링, 초기 챗봇·QA)에 쓰여요(교안).

자세한 풀이 — NLTK의 특징과 쓰임(교안) (펼쳐 보기)
  1. 주요 기능: 토큰화·품사 태깅, 구문 분석, WordNet 의미 분석, 머신러닝 텍스트 분류, 말뭉치 관리.

  4. 실무 활용: 시제품과 개념 검증, 전처리·정제, 감정 분석·의견 마이닝, 주제 모델링, 초기 챗봇·QA.

이 칸의 한계 · 기능 목록만으로는 실제 문장이 어떻게 바뀌는지 안 보여요. 다음 칸에서 교안의 영어 문장을 한 단계씩 처리해 봐요.

2영어 전처리 실습

교안의 영어 문장을 한 단계씩 — 소문자, 토큰화, 구두점, 불용어

실습: 영문 텍스트 전처리 기초순서: 소문자 → 토큰화 → 구두점 제거 → 불용어 제거

교안 실습은 영어 문장 하나를 네 단계로 다듬어요. 모두 소문자로 바꾸고, 단어로 자르고, 느낌표·마침표 같은 구두점을 빼고, the·is 같은 불용어를 빼면 내용어 11개가 남아요. 이어서 긴 글을 문장 단위로 자르는 실습도 해요.

이 칸에서 가져갈 한 가지

전처리는 원문을 "분석할 단어 목록"으로 바꾸는 공정이다. 단계마다 결과를 찍어 보며 빠진 것과 남은 것을 확인해야 한다.

왜 이 방법을 쓰나

문제 상황

"Hello!"와 "hello", "This"와 "this"를 컴퓨터는 다른 단어로 세요. 마침표도 단어 하나로 세고요.

앞 방법의 한계

원문을 그대로 세면 같은 단어가 여러 개로 갈라지고, 구두점·불용어가 상위권을 차지해 내용이 안 보여요.

해법

대소문자를 통일하고(lower), 토큰으로 자르고(word_tokenize), 구두점과 불용어(stopwords)를 걸러요. 긴 글은 먼저 문장으로 나눠요(sent_tokenize).

쉽게 말하면 장 보기 전에 메모를 정리하는 것과 같아요. 같은 품목은 합치고, "그리고·좀" 같은 말은 지우죠.

일상으로 치면

"우유! 우유 2개, 그리고 계란 좀"을 "우유 2, 계란"으로 정리하면 장보기가 쉬워져요.

자연어 처리로는

교안 실무 팁 세 가지: ① 전처리는 모든 텍스트 분석의 첫 단계로 품질에 큰 영향을 준다. ② 분야(도메인)에 맞게 불용어 목록을 고치면 정확도가 오른다. ③ NLTK의 FreqDist로 빈도를 본 뒤 추가 전처리 방향을 정한다.

조수(하루)

각 단계의 결과는 교안의 실행 결과 그대로예요. 원문은 교안에서도 뒷부분이 잘려 있어요.

실험 — 영어 문장 전처리 따라가기

자세한 풀이 — 영어 전처리 핵심(교안) (펼쳐 보기)
  1. 대소문자 통일(Case normalization).
  2. 축약형 처리(Contraction handling): don't → do + n't.
  3. 어간 추출 또는 표제어 추출(3-1쪽 칸 ③).
  4. 불용어 제거, 그리고 NLTK·spaCy 같은 라이브러리 활용.

이 칸의 한계 · 전처리로 단어 목록은 얻었지만, 각 단어가 문장에서 무슨 역할(명사·동사)을 하는지, 어떤 단어가 많이 나오는지는 아직 몰라요. 다음 칸이에요.

교안의 파이썬 코드로 보면 (몰라도 됩니다)
text = text.lower()모두 소문자로 바꿔요.
tokens = word_tokenize(text)단어와 구두점을 토큰으로 잘라요.
no_punct = [w for w in tokens if w not in string.punctuation]구두점 토큰을 빼요.
stop_words = set(stopwords.words('english'))영어 불용어 목록을 불러와요.
filtered = [w for w in no_punct if w not in stop_words]불용어를 빼요.
sentences = sent_tokenize(text)긴 글을 문장 단위로 나눠요.
3품사와 빈도

품사 태깅과 빈도 분석 — 단어의 역할과 횟수

방법: 품사 태깅(POS tagging) · 빈도 분석(Counter)태그: NNP · VBZ · JJ · NNS

품사 태깅은 각 토큰에 명사·동사·형용사 같은 문법적 역할을 붙이는 일이에요. 영어는 단어의 위치와 형태로 품사가 정해져서 토큰화와 품사 태깅이 자연어 이해의 핵심 단계예요. 다음으로 전처리된 단어를 세어 가장 많이 나온 단어를 찾아요.

이 칸에서 가져갈 한 가지

품사 태깅은 "이 단어가 문장에서 무슨 일을 하나", 빈도 분석은 "어떤 단어가 몇 번 나왔나"를 알려 준다. 둘을 합치면 "많이 나온 명사"처럼 핵심어를 고를 수 있다.

왜 이 방법을 쓰나

문제 상황

리뷰 1만 건에서 "제품의 무엇"이 화제인지 알고 싶어요. 단어를 다 세면 동사·전치사까지 섞여요.

앞 방법의 한계

품사를 모르면 "like(좋아하다)"와 "like(~처럼)"를 구별 못 하고, 명사만 골라 셀 수도 없어요.

해법

품사 태깅으로 역할을 붙인 뒤 필요한 품사(예: 명사)만 골라 세요. 교안은 Counter로 상위 3개를 뽑아요.

쉽게 말하면 회의록에서 "누가·무엇을"에 해당하는 말에만 형광펜을 칠한 뒤, 몇 번 나왔는지 세는 거예요.

일상으로 치면

회의록의 사람 이름에는 노랑, 할 일에는 초록 형광펜을 칠하면 역할별로 정리돼요. 그다음 가장 많이 나온 이름을 세죠.

자연어 처리로는

교안의 품사 태깅 결과: NLTK/NNP(고유명사) provides/VBZ(3인칭 단수 동사) easy-to-use/JJ(형용사) interfaces/NNS(복수 명사) to/TO over/IN(전치사) 50/CD(숫자) corpora/NNS. 빈도 실습: 전처리된 11개 단어에서 Counter의 상위 3개는 data 3번, natural 2번, language 2번.

태그는 교안 실행 결과 그대로예요. 영어 태그의 뜻을 한국어로 덧붙였어요.

실험 — 이 토큰의 품사는? — 교안 품사 태깅 결과

실험 2 — 교안 빈도 실습 — 전처리된 11개 단어 세기

자세한 풀이 — 품사 태깅과 빈도 분석(교안) (펼쳐 보기)
  1. 품사 태깅: pos_tag로 토큰마다 태그를 붙여요(NNP, VBZ, JJ, NNS, TO, IN, CD…).
  2. 의미: 품사 태깅은 단어의 문법적 역할을 분석해 의미 파악과 구문 분석의 기초가 돼요.
  3. 빈도 분석: 전처리된 단어 목록을 Counter로 세고 most_common(3)으로 상위 3개를 봐요 → data 3, natural 2, language 2.
  4. 실무 팁: FreqDist로 빈도를 보고 추가 전처리 방향(불용어 추가 등)을 정해요.

이 칸의 한계 · 빈도는 "많이 나온 말"을 알려 주지만 모든 문서에 흔한 말인지 이 문서에만 많은 말인지는 몰라요. 그 구별이 4회차의 TF-IDF예요.

교안의 파이썬 코드로 보면 (몰라도 됩니다)
tagged = pos_tag(words)토큰마다 품사 태그를 붙여요.
word_counts = Counter(processed_text)단어마다 몇 번 나왔는지 세요.
word_counts.most_common(3)가장 많이 나온 3개를 보여 줘요.

정리

칸새로 생긴 능력남은 한계
① NLTK 소개NLTK는 50개가 넘는 말뭉치·어휘 자원과 친절한 문서를 갖춘 "배우고 시험해 보는" 도구다. 대량·실시간 서비스에는 다른 도구를 함께 검토한다.교육·시제품에 강하지만 대량 실시간 처리는 spaCy 등이 유리
② 영어 전처리 실습전처리는 원문을 "분석할 단어 목록"으로 바꾸는 공정이다. 단계마다 결과를 찍어 보며 빠진 것과 남은 것을 확인해야 한다.기본 불용어 목록은 도메인에 안 맞을 수 있음("like"가 남음)
③ 품사와 빈도품사 태깅은 "이 단어가 문장에서 무슨 일을 하나", 빈도 분석은 "어떤 단어가 몇 번 나왔나"를 알려 준다. 둘을 합치면 "많이 나온 명사"처럼 핵심어를 고를 수 있다.빈도는 문서 전체의 흔한 말과 이 문서만의 말을 구별 못 함(→ TF-IDF)
