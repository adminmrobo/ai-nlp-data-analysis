큰 그림 — 이 회차가 흘러가는 4단계 (펼쳐 보기)

① 뉴스와 여론

뉴스·여론 분석은 "지금 사람들이 무엇에 관심을 두고 어떻게 느끼는가"를 빨리 읽어 다음 행동(제품 개선, 선거 전략, 정책 수정)을 정하는 데 쓴다.

② 감성 분석

③ ChatGPT와 일

④ 다음 쪽

분석하려면 데이터를 먼저 모으고 다듬어야 한다. 파일·API·크롤링으로 어떻게 모으고, 무엇을 걸러 낼까?

문제 상황

쉽게 말하면 설문지를 돌리는 대신, 동네 시장에서 사람들이 무슨 얘기를 하는지 매일 들어 보는 거예요.

2감성 분석

이 리뷰는 좋다는 말일까 — 감성 분석과 비즈니스 활용

방법: 감성 사전(규칙) 기반 감성 분석일상: 쇼핑몰 리뷰 · 고객의 소리(VOC)

교안은 감성 분석을 "이 글이 좋은 말이냐, 나쁜 말이냐"로 소개해요. 긍정·부정에, 판단을 보류하거나 정보만 주는 중립을 더해 세 방향으로 나눕니다. 먼저 긍정·부정 단어 사전으로 점수를 매기는 규칙 방식부터 해 봐요.

이 칸에서 가져갈 한 가지

감성 사전(규칙)은 빠르고 설명하기 쉽지만 부정어·신조어·비꼬는 말에서 틀린다. 규칙을 끝없이 더하는 대신 데이터로 배우는 쪽으로 넘어간다.

왜 이 방법을 쓰나

문제 상황

리뷰가 하루 수천 건, 댓글은 100만 건이 쌓여요. 사람이 하나하나 읽을 수 없어요.

앞 방법의 한계

단어 몇 개만 세면 "좋지 않아요"(좋다 + 부정)를 긍정으로 착각해요.

해법

교안의 순서대로 정규화 → 토큰화 → 불용어 제거로 다듬은 뒤, 긍정 단어(좋다·추천)와 부정 단어(실망·불만족) 사전으로 점수를 더해요. 부정어·신조어 규칙을 더해 보완합니다.

쉽게 말하면 채점표를 들고 리뷰를 훑으며 칭찬 단어에 +, 불평 단어에 −를 매기는 거예요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

"나쁘지 않아요"에는 나쁘다(−1)가 있는데 왜 긍정이에요?

학교 수학으로 보면 중학교 수학의 정수의 덧셈과 부호예요.

리뷰 점수 = Σ 단어 점수 (부정어가 오면 바로 앞 단어 점수의 부호를 뒤집음) · 점수 > 0 → 긍정, < 0 → 부정, = 0 → 중립
Σ모두 더하기
부호 뒤집기−1 → +1. "않·안·못"이 앞말을 부정
= 0감성 단어가 없거나 서로 상쇄되면 중립
숫자로 한 번 해 보기"좋지 않아요, 실망입니다": 좋(+1) → 않(뒤집기, −1) → 실망(−1) = −2 → 부정 ✓부정어 규칙이 없으면: 좋(+1) + 실망(−1) = 0 → 중립 ✗"나쁘지 않아요": 나쁘(−1) → 않(뒤집기) = +1 → 긍정 ✓

뒤집기 규칙 하나로 두 리뷰가 바로 맞았어요. 그런데 "참 빨리도 오네요 ^^"는요…?

일상으로 치면

단골 가게 사장님은 리뷰를 훑으며 "최고", "실망" 같은 말로 분위기를 바로 읽어요. 비꼬는 말("참 빨리도 오네요")도 앞뒤 사정으로 알아채죠.

자연어 처리로는

감성 사전 방식은 빠르고, 왜 그렇게 판정했는지 설명하기 쉬워요. 하지만 신조어("갓생", "대박")는 계속 생기고 비꼬는 말은 단어만으로 알 수 없어요. 그래서 실무에서는 데이터로 학습한 모델이나 대규모 언어 모델(LLM)을 함께 씁니다.

  2. 여론 분석: 선거 후보나 정책 담당자는 여론을 빨리 읽어 행동과 정책 방향을 정해요.
  3. VOC(고객의 소리): 불만·제안·칭찬을 직접 듣는 창구예요. 분석하기 전에 모으고 정리하는 일 자체가 큰 과업입니다.
  4. 기계 번역과 ChatGPT: 파파고·구글 번역은 데이터로 번역하고, ChatGPT 이후에는 프로그래밍 언어 대신 일상어로 AI에게 일을 시킬 수 있게 됐어요.
  5. 주의: GPT는 그럴듯하지만 틀린 답을 낼 수 있어요. 이를 할루시네이션(교안 표기: 착시효과)이라 하고, 진위를 확인하는 단계가 필요합니다.

이 칸의 한계 · 이 칸의 규칙 방식은 사전에 없는 표현과 문맥을 다루지 못해요. 다음 회차부터는 데이터를 모으고 다듬는 과정(2회차)과 학습하는 모델로 나아갑니다.

업무에 쓸 때 알아 둘 것 (펼쳐 보기)

현장에 옮기면

기업은 VOC 분석 결과를 워드 클라우드로 띄워 경영진에게 보고하고, LLM 활용 성과는 성공률·만족도 그래프로 보여 줘요. 잘 모르는 사람도 한눈에 이해해 설득력이 높아집니다(교안).

LLM으로 분류하더라도 중의성·오탈자·이모티콘을 다듬는 전처리와, 일부를 뽑아 사람이 확인하는 단계는 여전히 필요해요(교안).

3ChatGPT와 일

기계 번역과 ChatGPT — 일상어로 AI를 쓰는 시대

활용: 기계 번역 · 대규모 언어모델(LLM)일: 반복 작업 맡기기, 환각 확인하기

파파고·구글 번역기는 쌓인 번역 결과물을 바탕으로 AI가 자동 번역해요. ChatGPT 같은 대규모 언어모델(LLM)이 나오면서 판이 뒤집혔어요. 예전엔 AI를 쓰려면 프로그래밍 언어를 배워야 했지만, 이제는 일상어로 말하면 됩니다.

이 칸에서 가져갈 한 가지

LLM은 반복 작업을 빠르게 맡아 주는 "게임 체인저"지만 그럴듯한 거짓(환각)도 말한다. 사람은 해석·적용·확인을 맡는다.

왜 이 방법을 쓰나

문제 상황

고객 응대 시나리오 수십 개, 해외 리뷰 수천 건 번역처럼 반복적이지만 시간이 많이 드는 일이 쌓여 있어요.

앞 방법의 한계

예전에는 AI 모델을 쓰려면 프로그래밍 언어부터 배워야 했고, 번역기는 뉘앙스·관용구에서 자주 어색했어요.

해법

LLM에게 일상어로 시키면 초안을 빠르게 만들어요. 대신 사람이 결과를 해석하고, 사실인지 확인하고, 현장에 맞게 고쳐요.

쉽게 말하면 일 잘하는 신입에게 초안을 맡기되, 결재 전에 사실 확인은 꼭 하는 것과 같아요.

일상으로 치면

초안을 빨리 쓰는 신입이 오면 팀은 반복 업무를 덜어요. 하지만 신입이 자신 있게 틀린 숫자를 쓰면 결재자가 잡아야 하죠.

자연어 처리로는

교안은 GPT를 게임 체인저로 봐요. 고객 응대 시나리오 개발이 빨라지고 분석 속도·효율이 오르지만, 엉뚱한 답이나 허위 정보(환각, Hallucination) 때문에 진위 판별이 필요해요. 반복 작업은 GPT에 맡기고, 사람은 해석과 적용 같은 창의적·전문적 역할을 맡는다는 것이 교안의 전망이에요.

자세한 풀이 — 기계 번역, ChatGPT, 그리고 일자리 (펼쳐 보기)
  1. 기계 번역: 파파고·구글 번역기는 번역 결과물 데이터를 바탕으로 AI가 자동 번역해요.
  2. 패러다임 전환: AI 활용에 프로그래밍 언어가 필수였던 시대에서, 일상어로 대화하듯 명령하는 시대로 바뀌었어요.
