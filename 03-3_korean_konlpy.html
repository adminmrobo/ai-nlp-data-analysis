1한국어의 특수성

한국어는 왜 띄어쓰기로 못 자를까 — 교착어, 자유 어순, 조사와 어미

특징: 교착어 · SOV 어순 · 조사 · 어미예: 먹었습니다 = 먹 + 었 + 습니다

한국어는 어근에 조사와 어미가 줄줄이 붙는 교착어예요. "먹었습니다" 한 어절에 먹(어간) + 었(시제) + 습니다(종결 어미)가 들어 있죠. 어순도 자유로워 "나는 밥을 먹는다"와 "밥을 나는 먹는다"가 같은 뜻이고, 문법 역할은 어순보다 조사가 정해요.

이 칸에서 가져갈 한 가지

한국어는 한 어절에 여러 형태소가 붙고 조사·어미가 문법을 맡는다. 그래서 띄어쓰기(어절)로는 부족하고 형태소 분석이 꼭 필요하다.

왜 이 방법을 쓰나

문제 상황

"학교에", "학교를", "학교에서부터"를 검색하면 모두 "학교" 이야기인데, 띄어쓰기로 자르면 서로 다른 단어 세 개가 돼요.

앞 방법의 한계

영어처럼 공백으로 자르면 조사·어미가 붙은 어절마다 다른 단어가 되어, 같은 말이 수십 갈래로 흩어져요.

해법

조사(격·보조·접속)와 어미(종결·연결·전성·선어말)의 종류를 알고, 형태소 분석기로 어근과 붙은 말을 떼어 내요.

쉽게 말하면 레고 블록이 붙어 있는 덩어리에서 기본 블록(어근)을 떼어 내야 같은 블록끼리 셀 수 있는 것과 같아요.

일상으로 치면

같은 빨간 블록이라도 다른 블록이 붙어 있으면 모양이 달라 보여요. 떼어 내야 같은 블록으로 셀 수 있죠.

자연어 처리로는

조사: 격조사(이/가, 을/를, 의, 에, 에서), 보조사(은/는, 도, 만, 까지), 접속조사(와/과, 하고, 랑), 조사 결합(에서부터, 만으로도). 어미: 종결(-다, -까, -네, -자), 연결(-고, -며, -거나, -지만), 전성(-ㄴ/은, -ㄹ/을, -는), 선어말(-시-, -었-, -겠-)(교안).

분류는 교안의 표를 따랐어요.

실험 — 이 조각은 어떤 조사·어미일까?

자세한 풀이 — 한국어 전처리의 특수성(교안) (펼쳐 보기)
  1. 교착어: 어근 + 접사의 복합 형태. "먹었습니다" = 먹- + -었- + -습니다. 하나의 어절에 여러 형태소가 들어가요.
  2. 복잡한 활용: 동사·형용사(용언)가 여러 형태로 바뀌어요.
  3. 자유로운 어순: 기본은 주어-목적어-동사(SOV)지만 문장 성분의 위치를 바꿀 수 있어요. 문법 역할은 조사가 정해요.
  4. 결론: 교착어, 자유 어순, 조사·어미 체계 때문에 형태소 분석이 필수이고, 어절 분리만으로는 효과적인 분석이 어려워요.

이 칸의 한계 · 무엇을 떼어 내야 하는지 알았으니, 이제 떼어 낼 도구를 골라야 해요. 한국어 형태소 분석기는 여러 개고 장단점이 달라요. 다음 칸이에요.

2분석기 고르기

한국어 형태소 분석기 다섯 — Okt, Mecab, Komoran, Kkma, Hannanum

도구: KoNLPy기준: 속도 · 정확도 · 신조어 · 설치

KoNLPy는 여러 한국어 형태소 분석기를 한데 묶은 파이썬 라이브러리예요. 교안은 다섯 분석기를 속도·정확도·활용 상황으로 비교해요. 정답 분석기는 없고, 데이터와 목적이 고릅니다.

이 칸에서 가져갈 한 가지

속도는 Mecab > Komoran > Okt > Hannanum > Kkma. 신조어는 Okt, 세밀한 품사는 Kkma, 대용량·실시간은 Mecab, 전문 용어는 Komoran. 정확도는 문맥과 도메인에 따라 다르다.

왜 이 방법을 쓰나

문제 상황

SNS 댓글 100만 건과 법률 문서 300건을 같은 분석기로 돌려도 될까요?

앞 방법의 한계

아무 분석기나 쓰면 댓글의 신조어를 엉뚱하게 자르거나, 대용량에서 너무 느리거나, 학술 문서에서 품사가 거칠어요.

해법

데이터 성격(신조어·전문 용어·양)과 요구(속도·세밀함)를 보고 분석기를 골라요. 설치 난이도도 따져요(Mecab은 설치가 복잡).

쉽게 말하면 출퇴근용 자전거, 짐 나르는 트럭, 정밀 작업용 핀셋처럼 일에 맞는 도구를 고르는 거예요.

일상으로 치면

같은 "자르기"도 빵칼, 가위, 메스가 쓰임이 달라요. 빨리 많이 자를지, 정밀하게 자를지에 따라 골라요.

자연어 처리로는

교안의 Okt 실행 결과: "자연어 처리는 컴퓨터가 인간의 언어를 이해하고 처리하는 기술입니다." → 자연어 / 처리 / 는 / 컴퓨터 / 가 / 인간 / 의 / 언어 / 를 / 이해 / 하고 / 처리 / 하는 / 기술 / 입니다 / . 명사만 뽑으면(nouns) 자연어·처리·컴퓨터·인간·언어·이해·기술 같은 핵심어가 남아요.

실험 — 이 데이터엔 어느 분석기?

자세한 풀이 — 분석기 비교와 실습(교안) (펼쳐 보기)
  1. 속도: Mecab > Komoran > Okt > Hannanum > Kkma.
  2. 세분화: Kkma가 가장 세밀한 품사 태깅. 신조어: Okt가 강점.
  3. 환경: Mecab은 설치가 복잡하고, 다른 분석기는 간편해요.
  4. 실습 흐름: morphs(형태소로 자르기) → pos(품사 태깅) → nouns(명사만 뽑기). Okt와 Mecab 결과를 나란히 비교해요.

이 칸의 한계 · 어느 분석기든 사전에 없는 말은 잘못 잘라요. "갓생"이나 회사 제품명은 사용자 사전으로 알려 줘야 해요. 다음 칸이에요.

3말뭉치와 사전

사전은 늘 낡는다 — 말뭉치와 사용자 사전, 분석기 고르기

방법: 사용자 사전 · 말뭉치일상: SNS 신조어 리뷰

말뭉치(코퍼스)는 자연어 처리를 위해 모은 대규모 텍스트 집합이에요. 형태소 분석기는 말뭉치로 학습하고 사전으로 단어를 알아봐요. 그래서 사전에 없는 신조어는 사용자 사전으로 알려 줘야 합니다.

이 칸에서 가져갈 한 가지

분석기는 사전에 있는 말만 제대로 자른다. 신조어·전문용어·고유명사는 사용자 사전에 올리고, 미등록어를 모아 주기적으로 고친다.

왜 이 방법을 쓰나

문제 상황

SNS 리뷰에 "갓생", "존맛탱", "내돈내산" 같은 말이 많아요.

앞 방법의 한계

기본 사전에 없는 말은 "갓 / 생", "존 / 맛 / 탱"처럼 잘려서 빈도도 검색도 틀어져요.

해법

사용자 사전에 신조어를 올리고, 분석 목적(속도·정확도·신조어)에 맞는 분석기를 골라요. 도메인과 비슷한 말뭉치를 쓰면 정확도가 올라가요.

쉽게 말하면 새로 생긴 가게를 지도 앱에 직접 등록해야 길 찾기에 나오는 것과 같아요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

사전을 고치면 얼마나 좋아지는지 어떻게 재요?

학교 수학으로 보면 초등 수학의 비율이에요.

미등록어 비율 = 사전에 없는 단어 수 ÷ 전체 단어 수 · 명사 추출 정확도 = 올바르게 뽑힌 명사 수 ÷ 뽑혀야 할 명사 수
미등록어사전에 없어 잘못 잘릴 수 있는 단어(OOV)
뽑혀야 할 명사사람이 정한 정답 목록
주기적 갱신미등록어를 기록(로깅)해 사전에 추가
숫자로 한 번 해 보기예시 문장 단어 8개 중 신조어 3개(갓생·존맛탱·내돈내산) → 미등록어 비율 3 ÷ 8 = 37.5%사전 없이 올바른 명사 5 / 8세 단어를 사용자 사전에 올리면 8 / 8, 미등록어 0%

단어 세 개를 사전에 올렸을 뿐인데 정확도가 63%에서 100%가 되네요. 사전 관리가 곧 품질 관리군요.

일상으로 치면

새로 문 연 가게는 지도 앱에 등록하기 전까지 검색에 안 나와요. 그래서 가게 주인이 직접 등록하죠.

자연어 처리로는

한국어 분석기는 KoNLPy로 묶여 있어요. Okt(신조어·줄임말, 중간 속도), Mecab(C++ 기반 매우 빠름·정확도 높음·설치 복잡), Komoran(사용자 사전 활용성 높음), Kkma(서울대, 세밀한 품사·느림), Hannanum(KAIST, 안정적). 세종 말뭉치, 국립국어원 말뭉치, 모두의 말뭉치 같은 자원과 도메인·신조어·고유명사 사용자 사전으로 정확도를 높여요(교안).

박사

신조어 버튼을 하나씩 눌러 사용자 사전에 올려 보세요.

주판봇

분석기가 알아서 하겠지. 사전까지 내가 챙겨야 해?

조수(하루)

사전이 없을 때 잘린 모양은 전형적인 예시예요. 분석기마다 실제 결과는 달라요.

실험 — 신조어를 사용자 사전에 올리기

자세한 풀이 — 분석 정밀도를 높이는 전략(교안) (펼쳐 보기)
  1. 말뭉치: 대상 도메인과 비슷한 말뭉치를 고르고, 정제·전처리 품질을 관리하고, 크기와 다양성, 최신성을 챙겨요.
  2. 사용자 사전: 도메인 특화(의료·법률·IT 용어), 신조어·유행어, 고유명사(인명·지명·기관명)를 추가해요.
  3. 운영: 미등록어를 기록해 주기적으로 사전을 고치고, 사용자 사전의 우선순위를 조정하고, 결과를 검증해 피드백해요.
  4. 분석기 고르기(교안): 속도는 Mecab > Komoran > Okt > Hannanum > Kkma, 세밀한 품사는 Kkma, 신조어는 Okt. 정확도는 문맥과 도메인에 따라 달라요.
  5. 현업 활용(교안): 의미 기반 검색·질의응답(네이버·구글 자연어 질의), 고객 응대 챗봇(금융·쇼핑 주문·배송 조회), 감정 분석과 여론 모니터링(항공사 리뷰, 선거 동향), 다국어 번역에 형태소 분석이 바탕이 돼요.

이 칸의 한계 · 이제 단어를 잘 자를 수 있지만, 단어는 여전히 글자 그대로예요. "배송"과 "택배"가 비슷하다는 것, 어떤 단어가 이 문서의 핵심인지는 단어를 숫자로 바꿔야 알 수 있어요(4회차).
