# 검토 보고서 — 수포자 스킬(교수법) + 페르소나 감사

대상: 「인공지능과 자연어 데이터 분석 — 연구실 해설」 10쪽 + 목차 (2026-11-20, v1.0)
독자 가정: 혼합형(수식 공포 + 결과 해석 어려움)을 가진 비전공 직장인·성인 학습자

## 1. 수포자 기준표 (0~3점, 21점 만점)

| 원칙 | 회차 쪽(8쪽) 수정 전 | 수정 후 | 근거 / 고친 것 |
|---|---|---|---|
| P1 원리 먼저 | 3 | 3 | 모든 부분이 "왜 이 방법을 쓰나(문제 → 앞 방법의 한계 → 해법)" 다음에 수식 |
| P2 과정 한 번 보이기 | 3 | 3 | 부분마다 "숫자로 한 번 해 보기"(검산 완료: TF-IDF 0.026, 코사인 0.91, 0.8²⁰ ≈ 1.2% 등) |
| P3 기호는 말로 먼저 | 2 | 2 | θ·φ·Σ·∈ 등은 읽는 법이 있으나 8회차 α가 빠져 있었음 → 보강. 수식 상자가 접혀 있어 기본 흐름엔 기호 없음 |
| P4 맥락과 연결 | 3 | 3 | 부분의 한계 → 다음 부분, 회차의 next_q → 다음 회차, 목차의 개념 흐름 |
| P5 현장 연결 | 3 | 3 | 부분마다 "업무에 쓸 때"(VOC·검색·스팸·챗봇·RAG) |
| P6 AI 결과 판단력 | 1 | 3 | 초파리의 의심 대사만 있고 연습 활동이 없었음 → 회차마다 "AI 판단" 확인 퀴즈 1문항(가상의 AI 출력에서 이상한 점 찾기) 추가 |
| P7 존중하는 어조 | 2 | 2 | "몰라도 됩니다" 안내 있음. 주판봇·초파리의 퉁명한 말투는 캐릭터 설정이라 유지 |
| **합계** | **17** | **19** | 양호 |

| 원칙 | 요약 쪽(5·10회) | 비고 |
|---|---|---|
| P1 2 · P2 3 · P3 2 · P4 3 · P5 3 · P6 1 · P7 3 | **17** | 계산 문제는 단계별 풀이·흔한 실수까지 있음. AI 판단 문항은 아직 없음(후속 과제) |

용어 점검: RMSE를 "예측 오차의 표준편차"로 쓴 원자료 표현을 "제곱 오차 평균의 제곱근"으로 고침. 로그의 밑(log₁₀/ln) 명시. 상관/인과, 모수/비모수 혼용 없음.

## v2 (2026-11-20) — 회차×3쪽 확장판 재검토

**바뀐 것:** 회차당 한 쪽(부분 3개)이던 구성을 교안 학습내용 하나당 한 쪽(부분 3개)으로 펼쳤다. 강의 24쪽 + 5회·10회 요약 + 목차 = 27개 HTML. 앞 판의 부분 24개는 해당 쪽으로 옮기고, 교안에서 빠졌던 내용으로 새 부분 48개를 썼다.

**분량:** 부분 본문 글자 수가 회차마다 앞 판의 약 2.3~2.5배(회차당 약 1.1~1.4만 자)로, 교안 원고 본문(0.8~1.3만 자)과 같거나 많은 수준이 되었다(8회차는 실습 설명을 풀어 쓰며 163%).

**수포자 기준 자체 채점(강의 쪽 평균, 21점 만점)**

| P2 과정 한 번 보이기 | 3 | 계산이 있는 부분마다 수식 상자의 「숫자로 한 번 해 보기」(완전성, Vⁿ, 정규화 빈도, 로그 TF, 자카드, 시그모이드, wⁿ, 소프트맥스, BLEU, 포지셔널 인코딩 등) — 모두 파이썬으로 검산 |

**남은 보완과제**
1. 새 쪽 표지는 자동 생성판(캐릭터 팩 + 쪽 용어 칩)이다. 장면 그림을 새로 그리려면 COVER_PROMPTS를 쪽 단위로 늘려야 한다.
2. 쪽이 26개라 같은 캐릭터 소개·타워 안내가 반복된다(쪽당 약 15만 자 중 공통 부분). 필요하면 공통 부분 접기를 검토.
3. 5회·10회 요약 페이지의 교안 문항은 앞 판 그대로이며, 새로 펼친 학습내용(개발환경, 시각화, 신경망 기초 등)의 문항은 각 쪽 퀴즈에만 있다.
