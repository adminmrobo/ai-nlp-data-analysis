# 검토 보고서 — 수포자 스킬(교수법) + 페르소나 감사

대상: 「인공지능과 자연어 데이터 분석 — 연구실 해설」 10쪽 + 목차 (2026-11-20, v1.0)
독자 가정: 혼합형(수식 공포 + 결과 해석 어려움)을 가진 비전공 직장인·성인 학습자

## 1. 수포자 기준표 (0~3점, 21점 만점)

| 원칙 | 회차 쪽(8쪽) 수정 전 | 수정 후 | 근거 / 고친 것 |
|---|---|---|---|
| P1 원리 먼저 | 3 | 3 | 모든 칸이 "왜 이 방법을 쓰나(문제 → 앞 방법의 한계 → 해법)" 다음에 수식 |
| P2 과정 한 번 보이기 | 3 | 3 | 칸마다 "숫자로 한 번 해 보기"(검산 완료: TF-IDF 0.026, 코사인 0.91, 0.8²⁰ ≈ 1.2% 등) |
| P3 기호는 말로 먼저 | 2 | 2 | θ·φ·Σ·∈ 등은 읽는 법이 있으나 8회차 α가 빠져 있었음 → 보강. 수식 상자가 접혀 있어 기본 흐름엔 기호 없음 |
| P4 맥락과 연결 | 3 | 3 | 칸의 한계 → 다음 칸, 회차의 next_q → 다음 회차, 목차의 개념 사다리 |
| P5 현장 연결 | 3 | 3 | 칸마다 "업무에 쓸 때"(VOC·검색·스팸·챗봇·RAG) |
| P6 AI 결과 판단력 | 1 | 3 | 초파리의 의심 대사만 있고 연습 활동이 없었음 → 회차마다 "AI 판단" 확인 퀴즈 1문항(가상의 AI 출력에서 이상한 점 찾기) 추가 |
| P7 존중하는 어조 | 2 | 2 | "몰라도 됩니다" 안내 있음. 주판봇·초파리의 퉁명한 말투는 캐릭터 설정이라 유지 |
| **합계** | **17** | **19** | 양호 |

| 원칙 | 요약 쪽(5·10회) | 비고 |
|---|---|---|
| P1 2 · P2 3 · P3 2 · P4 3 · P5 3 · P6 1 · P7 3 | **17** | 계산 문제는 단계별 풀이·흔한 실수까지 있음. AI 판단 문항은 아직 없음(후속 과제) |

용어 점검: RMSE를 "예측 오차의 표준편차"로 쓴 원자료 표현을 "제곱 오차 평균의 제곱근"으로 고침. 로그의 밑(log₁₀/ln) 명시. 상관/인과, 모수/비모수 혼용 없음.

## 2. 페르소나 평가 (5점 만점)

| # | 페르소나 | 점수 | 한 줄 총평 |
|---|---|---|---|
| A | 마케팅 3년차, NLP 처음(입문) | ★★★★☆ (4.0) | 3줄 요약·실험만으로 따라갈 수 있음. 수식 상자를 펼치면 여전히 기호가 많음 |
| B | A의 팀장(보고서를 판단) | ★★★★☆ (4.0) | 대결·AI 판단 문항이 "숫자를 어떻게 의심할지"를 줌. 페이지가 길어 한 번에 보기 부담 |
| C | 파이썬 하는 데이터 분석가 | ★★★½☆ (3.5) | 실험은 좋으나 코드는 접힌 조각뿐, 돌려 볼 노트북(Colab)이 없음 |
| D | 원 강의 수강생(성인 학습자) | ★★★★☆ (4.0) | 교안 오류를 바로잡은 목록이 유용. 회차 번호(원 5~8 → 6~9)가 처음엔 헷갈림(목차·바닥글에 안내) |
| E | 원자료 저자 | ★★★★☆ (4.0) | 원자료와 다르게 쓴 곳이 쪽마다 명시됨. 2회차 R·IDE 내용이 줄어 있음 → 일부 보강 |
| F | NLP 연구자(분야 전문가) | ★★★½☆ (3.5) | 개념은 정확. RNN 기억(wᵗ)·정보 병목·셀프 어텐션 투표는 단순화 모형이라고 밝혔으나 실제 메커니즘과 차이 있음. 9회차 모델 정보는 교안 시점(2025) 기준 |

입문 독자(4.0)와 전문가(3.5)의 차이 0.5점 — 완료 기준(1점 이내) 충족.
