## 우선순위 보완과제 Top 5

1. **요약 쪽(5회·10회) 범위 넓히기** — 새 칸 48개에서 회차당 2~3문항(총 약 20문항) 추가, 쪽 번호 링크(P4).
2. **요약 쪽에 AI 판단 문항** — 회차당 1개, 총 8개(P6).
3. **본문 속 함수 이름 빼기** — 3-1·3-2의 4곳을 말로 바꾸고 이름은 코드 접기 상자로(P3, 비전공자판 문장 규칙 4).
4. **LSTM 게이트 풀이(7-2 칸③) 순서 바꾸기** — 게이트마다 말 풀이를 먼저, 기호식은 뒤(P3).
5. **새 칸 48개에 「업무에 쓸 때 알아 둘 것」** — 칸마다 한두 줄, 그리고 90자 넘는 나열문 55곳을 ①②③로 끊기(P5, P3).

## 문제 문장 → 고친 문장 (예)

| 위치 | 지금 | 고친 문장 |
|---|---|---|
| 7-1 칸② 비유 | 하지만 "점수 7"보다 "확신도 99%"가 이해하기 쉽죠. | 그래도 듣는 사람에게는 "점수 7"보다 "확신도 99%"가 더 잘 전해져요. |
| 3-2 칸② 해법 | 대소문자를 통일하고(lower), 토큰으로 자르고(word_tokenize), 구두점과 불용어(stopwords)를 걸러요. | ① 대소문자를 통일하고 ② 단어로 자르고 ③ 구두점과 불용어를 걸러요. 쓰는 함수 이름은 아래 코드 상자에 있어요. |
| 7-2 칸③ 풀이 | 망각 게이트 f_t = σ(W_f·[h_(t−1), x_t] + b_f): 이전 정보 중 버릴 것과 지킬 것을 0~1로 정해요 | 망각 게이트는 이전 기억 가운데 얼마를 남길지 0(다 버림)~1(다 남김)로 정해요. 식으로는 f_t = σ(W_f·[h_(t−1), x_t] + b_f)이고, σ(시그모이드)가 0~1을 만드는 장치예요. |
| 9-2 칸① 일상 비유 | 교안의 두 단계: ① 사전훈련 — 대규모 텍스트 코퍼스에서 … ② 미세조정 — … (한 문장 107자) | 교안은 두 단계로 나눠요. ① 사전훈련: 많은 글로 언어의 일반 패턴을 배워요(GPT, BERT). ② 미세조정: 우리 작업 데이터로 조금 더 배워 전문화해요(감정 분석, 분류). |
