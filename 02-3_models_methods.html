1NLP의 발전

자연어 처리는 어떻게 발전해 왔나 — 그리고 왜 전처리가 중요한가

개념: 자연어 처리(NLP)의 정의와 범위흐름: 규칙 → 통계 → 신경망 → 트랜스포머

자연어 처리(NLP)는 사람의 언어를 컴퓨터가 처리하는 기술이에요. 번역, 요약, 감성 분석, 챗봇처럼 쓰임이 넓고, 딥러닝 이후 발전이 빨라졌어요. 교안은 모델의 발전 과정을 보여 준 뒤, 어떤 모델이든 전처리가 성능을 좌우한다고 강조해요.

이 칸에서 가져갈 한 가지

자연어 처리 모델은 규칙 → 통계 → 신경망 → 트랜스포머로 발전했지만, 어떤 모델이든 먹는 것은 전처리된 데이터다.

왜 이 방법을 쓰나

문제 상황

"요즘 AI는 다 GPT"라고 들으면, 이 강의에서 왜 N-gram이나 TF-IDF 같은 옛 방법을 배우는지 궁금해져요.

앞 방법의 한계

최신 모델만 알면 그 모델이 앞 세대의 어떤 한계를 풀었는지, 언제 옛 방법이 더 나은지 판단할 수 없어요.

해법

세대마다 "앞 세대의 한계 → 새 해법"으로 이어 보면 각 방법의 쓰임새가 보여요. 그리고 모든 세대에 공통인 전처리를 먼저 챙겨요.

쉽게 말하면 스마트폰을 이해하려면 피처폰이 무엇을 못 했는지 아는 게 도움이 되는 것과 같아요.

일상으로 치면

삐삐 → 피처폰 → 스마트폰으로 바뀔 때마다 앞 세대가 못 하던 일을 하게 됐어요. 그래도 배터리 충전은 어느 세대나 필요하죠.

자연어 처리로는

규칙 기반은 사람이 문법을 써 넣었고, 통계 기반은 빈도로 확률을 셌고, 신경망은 문맥을 배웠고, 트랜스포머는 긴 문장 전체를 한 번에 봐요. 그래도 어느 세대든 글을 토큰으로 나누고 정규화하는 전처리(배터리 충전)가 필요해요. 교안: "전처리는 모델 성능에 큰 영향을 미친다."

2언어 모델

말에 확률을 매기다 — 통계 기반 언어 모델(N-gram)

방법: 바이그램 언어 모델 · 평활일상: 검색어 자동완성

교안은 언어 모델을 "주어진 문장 또는 단어 순서에 확률을 할당하는 모델"로 정의해요. 가장 단순한 것은 앞 단어 하나를 보고 다음 단어의 확률을 세는 바이그램(N-gram)입니다.

이 칸에서 가져갈 한 가지

언어 모델은 "다음에 올 단어는?"에 확률로 답한다. 통계 기반은 본 적 없는 단어 쌍에 0을 주는 희소성 문제가 있다.

왜 이 방법을 쓰나

문제 상황

검색창에 "배송이"를 치면 다음 말로 "빨라요"를 추천하고 싶어요.

앞 방법의 한계

단어를 세기만 하는 방식(앞 칸)은 순서를 버려서 "다음 말"을 예측할 수 없어요.

해법

말뭉치에서 "앞 단어 → 다음 단어" 쌍이 나온 횟수를 세고, 앞 단어가 나온 횟수로 나눠 다음 단어의 확률을 구해요.

쉽게 말하면 "배송"이 나오면 지금까지 그 뒤에 무슨 말이 몇 번 왔는지 세어 보는 거예요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

문장 전체의 확률은 어떻게 구해요?

학교 수학으로 보면 고등학교 「확률과 통계」의 조건부확률과 곱셈정리예요.

P(다음 | 지금) = 횟수(지금 다음) ÷ 횟수(지금 뒤에 무언가) · P(문장) = P(첫 단어 | 시작) × P(둘째 | 첫째) × …
횟수(지금 다음)두 단어가 이 순서로 붙어 나온 횟수
×곱셈정리: 앞에서부터 차례로 곱함
평활(+1)본 적 없는 쌍도 0이 되지 않게 분자에 1, 분모에 어휘 수를 더함
숫자로 한 번 해 보기예시 말뭉치 10문장에서 "배송" 뒤: 이 4번, 도 1번 → P(이 | 배송) = 4 ÷ 5 = 80%"이" 뒤: 빨라요 3, 늦어요 1, 좋아요 2, 싸요 1, 꼼꼼해요 1 → P(빨라요 | 이) = 3 ÷ 8 ≈ 38%"빨라요 이 배송"에는 말뭉치에 없던 쌍(시작→빨라요)이 있어 확률 = 0

곱셈이라 하나라도 0이면 전체가 0이 되는군요. 그래서 1을 더해 주는 평활이 필요했어요.

일상으로 치면

휴대폰 키보드는 "배송이"를 치면 "빨라요", "늦어요"를 추천해요. 우리가 자주 쓴 순서를 기억하기 때문이죠.

자연어 처리로는

통계 기반 언어 모델(N-gram, HMM)은 과거 데이터의 빈도와 확률로 순서를 모델링해요. 구현이 간단하고 적은 데이터로도 작동하지만, 희소성 문제가 있고 긴 문맥을 보지 못해요. 딥러닝 기반 모델(RNN·LSTM·트랜스포머·BERT·GPT)은 단어 사이의 긴 의존 관계를 학습하는 대신 많은 데이터와 계산이 필요합니다(교안 비교표).

자세한 풀이 — 자연어 처리 모델의 흐름(교안) (펼쳐 보기)
  1. 자연어 처리는 사람의 말을 컴퓨터가 처리하는 기술이고, 딥러닝으로 발전이 빨라졌어요.
  2. 언어 모델은 단어 순서에 확률을 매기고, 문맥과 패턴을 학습해 여러 응용의 바탕이 돼요.

  4. 딥러닝 기반: RNN, LSTM(7회차), 트랜스포머(8회차), BERT, GPT, T5(9회차) — 문맥 이해가 뛰어나지만 데이터·계산이 많이 듦.

이 칸의 한계 · 바이그램은 앞 단어 하나만 봐요. 단어를 "배송"이라는 글자 그대로 다루기 때문에 "배송"과 "택배"가 비슷하다는 것도 모릅니다. 단어를 숫자 벡터로 바꾸는 일(4회차)이 필요해요.

업무에 쓸 때 알아 둘 것 (펼쳐 보기)

데이터 분석으로 치면

검색어 자동완성, 맞춤법 교정, 음성 인식 후보 고르기에 언어 모델의 확률이 쓰여요.

이 실험의 말뭉치는 10문장이라 확률이 크게 흔들려요. 실제 모델은 수백만 문장 이상으로 셉니다.

같은 방법을 보여 주는 예시 코드 — 교안 코드 아님 (몰라도 됩니다)
from nltk import bigrams; pairs = list(bigrams(tokens))토큰 목록에서 이웃한 두 단어 쌍을 뽑아요.
Counter(pairs).most_common(5)가장 많이 나온 단어 쌍 5개를 세요.
3통계 대 딥러닝

통계 기반 대 딥러닝 기반 — 희소성은 왜 생길까

비교: N-gram·HMM 대 RNN·Transformer·GPT수학: 경우의 수(거듭제곱)

통계 기반 모델은 과거 데이터의 빈도와 확률로 언어 패턴을 계산해요. 구현이 간단하고 적은 데이터로도 돌아가지만, 단어를 n개씩 묶을수록 가능한 조합이 폭발적으로 늘어 말뭉치가 대부분을 한 번도 못 보는 희소성 문제가 생겨요. 딥러닝 기반은 이를 문맥 학습으로 풀지만 데이터와 계산이 많이 들어요.

이 칸에서 가져갈 한 가지

단어 묶음(n)이 길수록 가능한 조합은 어휘 수의 n제곱으로 늘어 말뭉치가 따라가지 못한다. 그래서 통계 모델은 긴 문맥에 약하고, 딥러닝은 많은 데이터·계산으로 이를 푼다.

왜 이 방법을 쓰나

문제 상황

"밥을" 다음 단어를 맞히려면 앞 한 단어만 봐도 될까요? "어제 친구랑 비싼 식당에서 밥을" 다음을 맞히려면 앞 여러 단어가 필요해요.

앞 방법의 한계

앞 단어를 많이 볼수록(n이 클수록) 세어야 할 조합이 어휘 수의 n제곱으로 늘어요. 말뭉치는 그 대부분을 한 번도 보지 못해 확률이 0이 돼요.

해법

딥러닝 모델은 조합을 하나하나 세지 않고, 단어를 벡터로 바꿔 비슷한 문맥끼리 정보를 나눠 써요. 그래서 긴 문맥도 다뤄요.

쉽게 말하면 모든 문장 조합을 외우는 대신, 비슷한 상황에서 무슨 말이 나왔는지 감을 익히는 거예요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

1만 개 단어로 3개 묶음을 만들면 왜 1조 개나 돼요?

학교 수학으로 보면 경우의 수, 거듭제곱(중학교)

가능한 n개 묶음 수 = Vⁿ (V: 어휘 수)
V서로 다른 단어 수(어휘 수)
n한 번에 보는 단어 수
Vⁿ각 자리에 V가지씩, n자리를 곱한 수
숫자로 한 번 해 보기V = 10,000, n = 2 → 10,000² = 1억 개n = 3 → 10,000³ = 1조 개말뭉치 100만 단어 ≈ 묶음 100만 개 → 1조 개 중 많아야 0.0001%

자물쇠 비밀번호 자리가 하나 늘 때마다 경우의 수가 10배씩 느는 것과 같은 원리네요.

일상으로 치면

예상 문제를 모두 외우는 학생은 처음 보는 문제에 막혀요. 원리를 익힌 학생은 비슷한 문제로 풀어내죠.

자연어 처리로는

통계 기반: N-gram, HMM, 최대 엔트로피 — 장점은 간단·저비용·적은 데이터, 단점은 희소성·문맥 한계·긴 문장 취약. 딥러닝 기반:
① RNN
② LSTM
③ Transformer
④ BERT
⑤ GPT
⑥ T5 — 장점은 복잡한 패턴과 문맥 이해·긴 문장
⑦ 단점은 많은 데이터·컴퓨팅 자원·높은 복잡성(교안 비교표).

박사

어휘 수와 n을 바꿔 가능한 조합 수를 보세요. 말뭉치 100만 단어가 그중 얼마를 덮을 수 있을까요?

주판봇

100만 단어면 충분히 크지! 다 세겠지.

초파리 연구원

어휘 1만 개, n = 3이면 조합이 1조 개야. 100만으로는 어림없어.

조수(하루)

"최대로 덮을 수 있는 비율"은 말뭉치의 모든 묶음이 서로 다르다고 가정한 상한이에요. 실제는 더 낮아요.

실험 — 단어 n개 묶음의 경우의 수와 희소성

실험 2 — 세대 비교표 — 이럴 땐 어느 쪽?

자세한 풀이 — 통계 기반 대 딥러닝 기반(교안 비교표) (펼쳐 보기)
  1. 기본 원리: 통계 기반은 과거 데이터의 빈도와 확률로, 단어 간 독립을 가정하고 순서 패턴을 계산해요. 딥러닝 기반은 신경망으로 단어 간 의존성과 긴 문맥을 배워요.
  2. 대표 모델: 통계 — N-gram, HMM(은닉 마르코프 모델), 최대 엔트로피. 딥러닝 — RNN, LSTM, Transformer, BERT, GPT, T5.
  3. 장점: 통계 — 간단, 계산 비용이 적음, 적은 데이터로도 작동. 딥러닝 — 복잡한 패턴과 문맥 이해, 긴 문장 처리.
  4. 단점: 통계 — 희소성, 문맥 한계, 긴 문장에 취약. 딥러닝 — 많은 학습 데이터와 컴퓨팅 자원, 높은 복잡성.

이 칸의 한계 · 희소성의 뿌리는 단어를 "서로 무관한 기호"로 다룬다는 데 있어요. 단어를 뜻이 담긴 숫자(벡터)로 바꾸는 법은 4회차 워드 임베딩에서 시작해요.

기준선 없이 딥러닝부터 시작하면 성능이 좋은지 판단할 근거가 없어요.
